# Независимый OUTPUT-review условного расчёта R3

Основной акт: [review.md](review.md), точный проверенный C `8a1ad4199fea09d1157972d7aa28eaad1e8e0337`.

Из корня репозитория:

```bash
.venv/bin/python -B verification/r5_r3_parametric_review/probe.py > /tmp/r5-sizing-independent.json
.venv/bin/python -B verification/r5_r3_parametric_review/reproduce.py
```

Первый скрипт пишет только stdout, независимо сверяет JSON/CSV/округлённые таблицы и новые синтетические случаи. Ожидания Decimal не используют авторский solve. Второй сохраняет новые логи **в этом каталоге review**, проверяет авторский пакет без его изменения, выполняет авторские readonly команды, тесты, check_registry и читает Git/PR. При повторном запуске дата, длительность тестов и состояние удалённого PR могут измениться; не принимать повторные служебные логи за исходные доказательства опубликованного акта.

`independent_results.json` содержит все ожидания и фактические результаты новых контрпримеров; `independent_command.json` — команду и SHA скрипта. `reproduction.json` содержит команды, окружение, источники, исходные/конечные SHA/size/mtime; `object_identity.json` связывает проверенные файлы с C/H. `power_analysis.json` содержит диагностические вычисления электрического бюджета по тем же входам, не новые проектные параметры. `evidence_hashes.json` фиксирует файлы акта и доказательств, кроме самого списка хэшей.

Синтетические числа проверок не являются исходными данными реального REV. Физические испытания NOT_RUN, G1 OPEN; оборудование, архитектура и ТЗ не утверждены.
