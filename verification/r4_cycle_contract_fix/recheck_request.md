# Независимый R5 RECHECK: разрешения CYC-01/08/09

Проверить новый неизменяемый C из следующего H (NEXT_MODEL.md и капсула
handoffs/T-r4-cycle-contract-01/r4-linked-20261111.md), ветка
work-r4/T-r4-cycle-contract-01/r4-linked-20261111 в https://github.com/narrateller/REV.
Автор R4 r4-linked-20261111; проверяющий должен быть независимым автором акта.

Основание — d99afb4c3231d641d4a4921f39987264ce5ffc23. B01/W01/W02 OPEN до вашего
решения, авторская проверка не закрытие. Предмет — только документальный контракт.

Обязательный объём:

1. Все 26 старых независимых случаев, сохранение 16 правильных и исправление
   10 старых ALLOWED_ASSUMED. Старый probe в истории не менять; baseline запускает
   его на старом C и должен показывать старые 10 расхождений.
2. Проверить самостоятельно полный entry каждого зависимого действия и binding
   с mode/state/READY target, отличия completion от разрешения старта. Повторить
   unknown receiver/resource/B closure и FALSE+UNKNOWN, включая startup/refill/
   возвраты; не ограничиваться успешным результатом авторского runner.
3. Scope/epoch/action/phase/subject revision, отсутствие/устаревание evidence,
   инвалидация после движения/нового факта и сохранение известного отказа.
   Насос не подменяет все потребители, READY не сохраняемый разрешающий бит.
4. Зависимый шаг не продвигается после BLOCKED/UNKNOWN без нового основания;
   утраченный столб не остаётся подтверждённым по label. Возможна адресная
   проверка/реставрация B по собственным условиям, без общего READY и без
   требования цели до старта. Другой отказ/UNKNOWN не очищается её успехом.
5. Реальное поступление после отказа сохраняется с идентичностью/неизвестной
   mass_record для сверки, а не игнорируется; дубликаты и конфликтующие факты
   не выдают нормальное разрешение/второе зачисление. Это documentary queue,
   не реализация физического/массового движка; W02 остаётся отдельным вопросом.
6. Неизменность L1–L5/численных слотов ресурсов, 17 input blobs, 11 protected
   trees, CAD candidate и всех исходных файлов акта R5. Diff двух documentary
   helper modules включить в review отдельно от неизменных CAD/расчётных tools.

Команды — README.md. Default команды read-only; results.json содержит полные
actual/expected, integrity_checks.json — два запуска/hash-size-mtime, текущие
document_checks.json/publication_checks.json — проверки целостности. Физическую
работоспособность/безопасность они не проверяют. Никакого solver/CAD/rebuild/
physical testing по этой эстафете. Архитектура/ТЗ/COTS не утверждаются, G1 OPEN.
