# События и неизменяемые инварианты

Все определения — ASSUMED_INTERFACE_PROPOSAL. Поля фактических масс/положений/
порогов UNKNOWN; перечень не является поддержкой событий старым engine.

| Event ID | Что меняется | Что не разрешается автоматически |
|---|---|---|
| AUDIT_INVENTORY | Подтверждение состава, lineage, начального остатка/пустоты по выбранной базе и history. | HOME/уровень не заменяют аудит; UNKNOWN не становится EMPTY. |
| DELIVER_DOSE | Ровно одна актуальная дозовая передача UPSTREAM → PRESS_ACCOUNT, уникальные dose/event ID. | Резервирование/взвешивание снаружи не означает поступления; готовый product не создаётся. |
| GATHER_PARTIAL | Перестройка состояния/геометрии той же массы в промежуточное, history дополняется. | Partial pressure/position не означают готовое изделие; новая доза не добавляется без DELIVER_DOSE. |
| ESTABLISH_COLUMN | Фиксация выполнения критериев H-A с сохранением фактического retained inventory. | Нельзя вставить неучтённую пробку/столб или обнулить стартовое накопление. |
| SELECT_BATCH | Завершение набора B по выбранным критериям, все входящие дозы/остатки связаны. | Не является выдачей/физическим доказательством достаточной массы. |
| COMPACT | Материальное преобразование с criterion/history/parent lineage и сохранением L1–L3. | CREATE готового product из пустоты, чисто временной триггер, дублирование parent+product. |
| IDENTIFY_SEGMENT | Непересекающаяся учётная граница outgoing/retained с parent/children и остатком. | Не доказывает физическое отделение; unsupported SPLIT остаётся INDETERMINATE. |
| START_EJECTION | Позиционное движение выбранного объекта при guard подачи/удержания или открытия B. | Не списывает вещество и не подтверждает receiving. |
| CROSS_EXIT_COMPLETELY | Location: OUTSIDE_PENDING_RECEIPT после выхода **всего** объекта через выбранную границу. | Ownership/mass в PRESS_ACCOUNT сохраняются; выход только передней грани/части не подходит. |
| ACK_RECEIPT | Актуальная согласованная передача transfer_id/массы/идентичности → RECEIVER_ACCOUNT. | Не доказывает, что product/residue не пересекают reset sweep или покинули MODEL_DOMAIN. |
| REMOVE_GEOMETRY | Геометрическое представление деактивируется после ACK и окончания взаимодействий. | Entity/mass не удаляются из общего журнала; clear не получают удалением мешающего тела. |
| RETURN_TOOLS | Изменение поз/подтверждений инструмента, удержание A проверяется отдельно. | Никакого product REMOVE, сброса остатков или whole READY. |
| RESET_B | Подтверждённые stop/lock closed в выбранной последовательности после clear/приёма/проверки sweep. | Нельзя закрывать через продукт/остаток или по одному факту возврата пуансона. |
| RECONCILE_NEXT_INVENTORY | Подведение текущего epoch: A retained column либо B выбранный допустимый остаток. | Не новая масса/изделие; не право на следующий цикл без CYC-09. |
| REQUEST_READY | Чтение совместного predicate заданного режима/назначения, не изменение материала. | Unknown conjunct не TRUE, reset fault/изменение actual controller/реальное разрешение не выдаются. |
| CHECK_FULL_CYCLE_BASIS | Аудит полноты оснований раннего CYC-08. | Не вычисляет время/энергию, не подменяет их временем оси или нулевыми aux. |

Обязательные инварианты:

- **I-ID:** event_id/transfer_id не переиспользуются для второго зачисления;
  entity_id/lineage не теряются между эпохами. Повторная доставка старого ACK —
  идемпотентная ссылка на существующую запись либо ошибка, не новая масса.
- **I-MASS:** L1–L4 соблюдаются на одной базе; unknown discrepancy не исправляется
  удалением тела/сбросом remainder. Разрешённый остаток B — критерий, не ноль.
- **I-PHASE:** сырой материал/partial gather не квалифицированы как продукт;
  transformation event и его основание обязательны. Начальный product запрещён
  для empty/startup case; известный остаток определяется собственным состоянием.
- **I-PARTITION:** outgoing и retained не содержат одно вещество дважды;
  children исчерпывают заданный parent с явным remainder/потерями/обменом.
- **I-CUSTODY:** location и ownership раздельны; pending — часть PRESS_ACCOUNT,
  а не второй независимый запас. Глобальный ledger живёт после REMOVE_GEOMETRY.
- **I-RECEIPT:** источник/время/объект ACK валидны, весь согласованный объект
  за определённой границей и согласован с receiver. UNKNOWN receiver не ACK.
- **I-CLEAR:** независимый positive clear/sweep predicate, не отсутствие тела
  после неподтверждённого удаления. Отсутствующий feedback не равен отсутствию помехи.
- **I-CONTINUITY:** положение/идентичность/массовая база/history согласованы
  на каждой границе; CREATE/SPLIT/перемещение в новую зону не скрывают разрыв.
- **I-READY:** READY имеет mode/target/epoch и включает узлы, материал,
  приёмник/ресурсы и valid feedback; RETURN_TOOLS не поднимает его автоматически.

Для переноса в модель требуются отдельные реализация/тесты lifecycle/контактов/
границ и актуальные входы. Этот пакет не меняет существующий engine/CAD.
