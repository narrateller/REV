# CYC-09 — ранний контракт совместной готовности

**ASSUMED_INTERFACE_PROPOSAL.** READY имеет `variant`, `mode`, `target`, `epoch`
и набор актуальных оснований. Это документальный predicate будущей модели,
не разрешение контроллера/безопасности. Реальные значения guards в contract.json
все UNKNOWN; фактическая готовность REV не установлена.

`READY(target) = material-state-allowed AND all(required_guards(target))`.
Известное нарушение/неверный state → BLOCKED; иначе хотя бы одно UNKNOWN →
INDETERMINATE; все TRUE дают только ALLOWED_ASSUMED в условном примере.
Отсутствующее/неподдерживаемое условие не превращается в TRUE. Устаревшее или
противоречивое подтверждение блокирует использование этого подтверждения;
надпись на state/entity не заменяет evidence.

## Targets и материал

Полный перечень guards каждого target дан в `contract.json: ready_targets` и
соответствующих REQUEST_READY transitions. Все targets требуют BASIS_DEFINED,
EVENT_FRESH, LEDGER_VALID, CONTINUITY_CONFIRMED, FEEDBACK_VALID, затем свои guards.

Загрузочные targets A startup/steady и B initial требуют также определённого
доступного приёмника RECEIVER_DEFINED; это готовность к передаче при выбранном
режиме, не преждевременный ACK будущего продукта. Состояния узлов ортогональны
материальным состояниям: возврат startup A и partial gather B сохраняет запас
и проверяет refill-позу, а не переводит материал в пустой/готовый продукт.

| Target | Допустимое материальное состояние | Дополнительное условие и отличие |
|---|---|---|
| A-READY-START-LOAD | A_EMPTY | Проверен пустой inventory, ось в исходном положении, feed clear, нет незавершённой передачи, ресурсы на загрузку. Готового столба не требует. |
| A-READY-START-PRESS | A_STARTUP_RAW / A_COLUMN_BUILDING | Известен запас, отсечение, реакция выбранного пуска, поддерживаемый метод/ресурсы. Готовность загрузить не доказывает возможность сжать. |
| A-READY-STEADY-LOAD | A_COLUMN_ESTABLISHED | Идентифицированный/удержанный столб и критерий его состояния, сохранённый inventory, feed clear, tools home, передача предыдущего сегмента завершена. |
| A-READY-PRESS | A_STEADY_LOADED | Сохранённый столб/доза, реакция/отсечение и ресурсы; COMPACTION_CRITERION ещё должен подтверждаться событием, а не READY до сжатия. |
| A-READY-EJECT | A_SEGMENT_READY | Явный partition, удержание остатка, весь путь проверяем и свободен, приёмник определён/доступен. ACK будущего сегмента не требуется заранее. |
| B-READY-LOAD | B_ACCEPTABLE_INITIAL | Допустимый известный остаток (или доказанный empty case), восстановленные stop/lock, ось home, feed clear, закрытый ledger прежних передач, ресурсы. |
| B-READY-REFILL | B_GATHERED_PARTIAL | Допустимое частичное состояние, известный inventory, восстановленная refill поза/вместимость и ресурсы. Не READY следующего законченного цикла. |
| B-READY-PRESS | B_BATCH_SELECTED | Набор завершён, отсечение, восстановленный силовой контур stop/lock и ресурсы. Product ещё не объявлен. |
| B-READY-EJECT | B_EJECTABLE | Подтверждённые разгрузка → unlock → open, partition, весь путь/приёмник/ресурсы. Физика открытия B INDETERMINATE. |

Следующий цикл выбирает **тот же определённый входной target**, после reconcile,
а не общий безымянный READY. Для A пуск/steady различаются. Для первого B
инвентарный audit должен подтвердить отсутствие незавершённых передач, но не
создаёт фиктивный ACK предыдущего несуществующего продукта. Первое восстановленное
состояние stop/lock тоже требует audit/feedback, не воображаемого RESET.

## Узлы и подтверждения

| Узел / интерфейс | Обязательство; реальные датчики/пороги UNKNOWN |
|---|---|
| Приём/бункер/дозатор | Для loading/refill — реальное наличие/поступление дозы, доступная вместимость, lineage, разрешённая поза тракта. Уровень сам по себе не определяет массу/базу. |
| Отсечение/стык | Для press/gather — закрытое подтверждённое отсечение; для подачи — определённый открытый путь и отсутствие конфликта. |
| Камера/пуансон/цилиндр | Поза и допустимое состояние хода/нагрузки, валидная обратная связь; home одной оси не заменяет состояние камеры. |
| Реакция/силовое замыкание | A retained/clamp/startup reaction по выбранному mode; B stop/lock closed для press, разгрузка/вывод/открытие для ejection. Геометрия рамы не доказывает нагрузочную способность. |
| Выход/приёмник | Граница и полный объект определены; путь/вместимость доступны. Предыдущая передача учтена, ACK не получен только по окончанию таймера. |
| Остаток/материал | A столб сохранён с history и удержанием; B остаток идентифицирован и допустим. Unknown mass/residue не ноль, готового product из raw нет. |
| Восстановление/сервисные зоны | Перед B reset: полный sweep свободен от product и residue, состояние инструментов/порядок восстановления подтверждены. Реальный L-путь обслуживания остаётся INDETERMINATE, прежние блокировки не закрыты. |
| Ресурсы/управление | Доступность ресурса следующего этапа/действительный feedback/epoch; данные насоса/потребителей и физическая достаточность не подтверждены. Сброс fault требует новой проверки истории. |

Наблюдение должно содержать source_id, event/entity/transfer IDs, epoch,
момент/интервал, метод и область применимости, итог TRUE/FALSE/UNKNOWN и evidence.
Численные допуски/threshold/validity-window UNKNOWN — не бесконечная допустимость
старого сигнала и не нулевая погрешность. Проверки механической безопасности и
соответствие стандартам этим документом не выполнены. Q-R2-01…05/Q-R3-01…05
ожидают ответов; окончательный CYC-09 после следующих интерфейсов, не самоприёмка.
