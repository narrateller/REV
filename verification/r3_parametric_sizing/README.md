Из `/workspace/REV`:

```bash
# Пересчёт и полное сравнение с сохранённым результатом без записи:
.venv/bin/python -B scripts/rev_parametric.py
# Арифметика/балансы/контрпримеры, не верификация физики:
.venv/bin/python -B -m unittest discover -s tests -p 'test_rev_parametric.py' -v
.venv/bin/python -B scripts/check_registry.py --check-git
```

`--write` явно сохраняет evidence/CSV и снимки после регистрации входов/выходов в params/registry.yaml; не генерирует CAD, не выполняет физические испытания и не меняет сам реестр. Default не пишет файлы. Изменение входа требует новой ревизии/согласованной регистрации зависимых результатов, затем реального пересчёта; ручная подмена хэшей запрещена. Для расширения модели API `solve(p, 'A'|'B')` принимает SI словарь значений из реестра. Нельзя передавать неизвестное как ноль или считать безымянный набор проектными данными.

Файлы report.md и phases.md — отображение округлённых значений; точные зарегистрированные значения/единицы и хэши в JSON/CSV. Код сверяет единицы входов, конечность, знаки, области κ/φ/КПД, положительность эффективных давлений, геометрию сжатия и балансы энергий. Снимки содержат точные параметры конкретного сценария и все его выходы, а не чужие независимые записи; это допустимый сохранённый реестр проектного поднабора с точным SHA-256. Источник R2 хранится отдельно со своим исходным SHA, его параметры не переопределяются этим пакетом.
