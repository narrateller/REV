## Перед изменением геометрии

Оформить входной акт по §6: наследуемые ASSUMED, размерности/оси/знаки,
границы применимости арифметики, обратные зависимости и открытые UNKNOWN.
Проверить source engineering hashes/revision/value/unit с активным registry,
повторить оба исходных readonly solver. При расхождении остановить зависимое
использование, не чинить источники/хэши ради прохождения проверки.

Зарегистрировать отдельные будущие CAD-входы/производные определения до их
применения. Существующие R3 ID читать из реестра по точным ревизиям. Дополнительные
положения, стенки, оболочки и сервисные размеры имеют отдельные ID ASSUMED,
происхождение, зависимости, null tolerance/неопределённость. Реальные параметры
REV остаются null/UNKNOWN с причиной. Статус CALCULATED наследует все ограничения
исходных гипотез и не превращается в VERIFIED/LOCKED по самопроверке.

## Обязательная связь CAD с расчётом

1. Сечение/длина камеры, продукт/доза, занятый объём, подход/сжатие/выдача и
   полный возврат читаются из BASE_A либо BASE_B размерного слоя. Записать
   соответствие базы камеры, поверхности пуансона, нуля/концов ходов и выходной
   границы существующей системе координат. Это явное исследовательское допущение,
   а не установленная ориентация реальной REV.
2. D — минимальный расчётный bore при заданном κ, d — расчётный шток; сохранить
   их отдельно от наружной оболочки цилиндра. Создать редактируемые bore/rod
   представления/параметры; не выдавать D за наружный диаметр или обоснование
   прочности, устойчивости, полной длины и монтажного исполнения. Ранее условные
   крепления допускаются только как явно неподтверждённые оболочки; зафиксировать
   их несовместимость/UNKNOWN, если новые D/d в них не помещаются. Конкретные
   фланцы/цапфы/порты/болты не подбирать без APPROVED_FOR_LAYOUT COTS.
3. Все новые t/v рабочих движений — только R3P_BASE_A/B_* fixed-budget. Не
   использовать старые исходные времена, legacy power-limited T или fixed-times
   как согласованный режим. Выдержка/aux A и unload/open B — отдельные условные
   интервалы с источниками; отсутствующие длительности/потребители UNKNOWN,
   не нули. Проверить S=v*t и границы общего времени без разрывов; согласование
   мощности не даёт разрешения контакта/материального процесса.
4. Силы/реакции/давления и Q передавать как сценарные интерфейсы, а не как
   подтверждение рамы, креплений или подбор гидростанции. Габариты бака/мотора,
   крепления/коммуникации/охлаждение не вычислять из одной мощности. Исходные
   оболочки сохранять ASSUMED либо явно заменять зарегистрированной гипотезой
   с причиной; скрытая геометрическая оптимизация под энергетику запрещена.
5. **B_open_permission INDETERMINATE**: геометрическое движение упора/замка
   возможно лишь в отдельно подписанной условной сцене. Фактические снятие
   реакции, разрешение открытия и общий READY этим не подтверждаются.

## Состав и сравнение

Сохранить весь состав A/B: приём/бункер/дозатор/стык/отсечение, камера/пуансон,
цилиндр/шток/опоры, рама/связи/крепления, A канал/зажим, B lock/end_stop,
выход/приём, ограждения, гидростанция/коммуникации и все QueryVolumes,
включая сервисные. Не удалять тела или пары для скрытия конфликтов.

Выходная таблица для **каждого** затронутого CAD параметра:

`CAD ID/свойство → BASE_A/B и режим → точный файл/JSON locator/ID@revision
→ значение SI/статус/зависимости → прежнее значение/статус → затронутые узлы
→ причина изменения/UNKNOWN → проверка`.

source_bindings.md в этом подготовительном пакете — каталог точных исходных
чисел, не свидетельство их применения. Будущий результат должен дополнить
его фактическими CAD ID/старым значением/проверенной native геометрией и показать
до/после сечений, общего вида, рабочих и сервисных положений. Неизменённые
параметры и несовместимые условные интерфейсы также перечислить.

Сохранить старый cad/build/feed_power и его доказательства неизменными.
Новый source/build пакет — в отдельных cad/calculated_layout и
cad/build/calculated_layout либо эквивалентном явно именованном каталоге.
Старые акты не распространяются автоматически на новые входы/геометрию.

## Построение, проверка, воспроизводимость

FreeCAD 1.0.0 + /usr/bin/python3, Part; точные версии сохранить при запуске.
Редактируемые FCStd для A/B, STEP, общие виды/сечения/фазовые изображения
SVG/PNG/PDF, manifest/параметры/сырые результаты/JSON и читаемый отчёт.
Открыть сохранённые FCStd/STEP, recompute и проверить фактическую native форму,
положение/размеры всех тел и QueryVolumes. Manifest/hash сам по себе не PASS.

Generation — отдельная явная команда. Verifier только читает уже сохранённые
артефакты: не генерирует, не чинит manifest/входы/доказательства. Два запуска
должны дать одинаковый результат без изменения SHA/size/mtime контролируемых
файлов. Повторная генерация в отдельном каталоге и последующая проверка должны
воспроизводить геометрию/параметры/исходы; timestamps контейнеров учитывать отдельно.

Использовать принятый вычислительный инструмент в его допустимой области,
без изменения frozen модулей. Новый адаптер, привязка, циклограмма и новая
геометрия требуют отдельного review. Если изменение инструмента необходимо,
отделить diff/основание и регрессии; не переносить прежний review автоматически.

- Рабочие фазы A/B: полный прямой ход, выдача, возврат, восстановление
  предусмотренной геометрии READY; отдельные link/contact/lifecycle/continuity
  и разрешение переходов. Четыре исходных случая на A/B и их отрицательные
  контрпримеры повторить с новыми входами; не расширять их вывод на весь пресс.
- Проверять весь интервал всех обязательных фаз/пар, не только конечные позы.
  Доказанная коллизия BLOCKED; неподдерживаемое/неизвестное обязательное условие
  INDETERMINATE без false CLEAR; known defect сохраняется при одновременном UNKNOWN.
- Повторить все затронутые сервисные пути цилиндра/штока, дозатора, вставок,
  A clamp/B stop/lock, ограждений, бака/мотора/соединений; полный выход и возврат,
  начальные/конечные poses, состав движущейся группы и все mandatory pairs.
  Исходный прямой UP с шестью BLOCKED парами и ограниченный L-путь показать
  отдельными строками: прежние статусы/свидетельства сохраняются, новые исходы
  пересчитываются, совпадение не предполагается. Физическая выполнимость L —
  INDETERMINATE. Нельзя объявлять изменённую геометрию исправленной старым актом.
- Воспроизвести регрессии предыдущих lifecycle/CAD/QueryVolume/semantic исправлений,
  включая пять false PASS R5 и составные ошибки; сохранить исходные тесты ядра.
- Все оставшиеся пересечения/условия в конечном перечне: native penetration,
  допустимое сопряжение с основанием, envelope overlap, INDETERMINATE с причиной.
  Для ранее исправленных групп — новая проверка отсутствия регрессии либо
  явная новая проблема, без исключений/удаления тел ради зелёного результата.

Разделить execution exit, совпадение теста с ожиданием, геометрический исход
и общий/физический исход. Неподтверждённая обязательная связь, блокированная
выдача, разрыв, неподтверждённый возврат исключают успешный sufficient-итог.
Физическая/энергетическая реализуемость всего пресса остаётся INDETERMINATE.
