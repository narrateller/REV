archive_rev7/manifest.json хранит исходные SHA256. Ни один REQ/VAL ID не удалён;
JSON каждой строки содержит lineage. Текст текущих двух документов заменён новой
DRAFT ревизией; старая редакция и её история сохранены в архиве/Git.
