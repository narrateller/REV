# Воспроизведение RECHECK R5

Область и вердикт: [review.md](review.md). Проверяемый C:
`4f31ed624336e1101b0ba04857f4316c73e4d375`.

Из корня репозитория, Python 3.12.14:

```sh
.venv/bin/python -B verification/r5_r4_cycle_contract_recheck/reproduce.py
.venv/bin/python -B verification/r5_r4_cycle_contract_recheck/independent_probe.py > /tmp/r5_cc_independent.json
```

Первая команда повторяет проверки, сохраняет stdout и проверяет неизменность
защищённых файлов; собственные логи/JSON в этой папке перезаписываются.
Вторая выводит собственные ожидания/контексты, не меняя входов. Сопоставить
с независимым сохранённым `independent_results.json`. Новые IDs и источники
evidence — явно ASSUMED fixture, не действительные подтверждения установки.

Ожидается 26/26 исправленных исходных случаев и **45 дополнительных случаев,
три расхождения**: два шага неадресного материального восстановления и забытый
отвергнутый operation ID. Код 0 означает завершённый сбор доказательств,
**вердикт остаётся REJECT_WITH_BLOCKER**. Старый probe запускается лишь как
исторический baseline на старых Git blobs, не как эталон ошибочных исходов.

`object_identity.json` задаёт хэши всех 41 файлов двух проверенных папок C/H.
`reproduction.json` содержит 17 входов и before/after 543 защищённых файлов.
`evidence_hashes.json` — SHA-256 файлов текущего акта (кроме самого manifest).
`final_checks.json` — проверки записи акта и сохранности перед публикацией.
Физические испытания, пересборка CAD и расчётные solver не запускаются.
