# Недостающие входы T-r3-force-path-01 — план получения, не расчёт

Общее правило: все поля ниже **UNKNOWN**, value=null, tolerance=null до
прослеживаемого источника/отдельной регистрации. Это перечень групп входов,
не новые значения активного реестра. Доступные условные F/D/d/section/strokes/
timing/скорости — только исходные 44 bindings BASE_A/B fixed-budget.

План получения не назначает claims другим участникам. Ненайденный вход остаётся
UNKNOWN; условный сценарий может показать зависимость/чувствительность, но не
закрывает этот пробел и не разрешает CAD, изготовление или движение машины.
