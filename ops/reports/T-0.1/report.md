# T-0.1 — геометрические гейты REV

Гейты G-ENV, G-MASS, G-COLL, G-FEED и G-CLEAR проверены в FreeCAD 1.1.4 под Windows. Позиционный запуск скрипта из `freecadcmd.exe` читает `REV_GATE_ARGS` и записывает UTF-8 JSON по схеме `rev.gate_report/1`. Отчёт содержит версию FreeCAD, версию и SHA-256 критериев. Коды возврата — 0 при PASS или WARN, 1 при FAIL, 2 при ошибке. При невалидном `REV_GATE_ARGS` с доступным `out` записывается отчёт с `overall: ERROR`. Недоступные метаданные в таком отчёте имеют значение `null`. Если путь отчёта неизвестен, диагностика выводится в stderr.

## Правила измерений и допущения

- Роли читаются из `RevRole`, материал из `RevMaterial`, плотность из `RevDensity_kg_m3`. Поля YAML `role`, `material` и `density_kg_m3` по сохранённой метке заполняют отсутствующие значения. Плотность по умолчанию 7850 кг/м³ взята из карточки. Физические роли — `machine`, `moving`, `punch`, `chamber_liner` и `hopper`. Виртуальный объём `feed_path` учитывается в G-FEED. Входную геометрию, уже учтённую в результате операции, исключает обход зависимостей. Оставшиеся объекты без `Solids` перечисляются в отчёте и повышают PASS до WARN.
- G-CLEAR назначает каждому пуансону ближайший вкладыш. `RevPair` может задать имя объекта, метку, ссылку FreeCAD или общую строку у двух объектов. Результат содержит все назначенные пары и максимальный измеренный зазор. Ось хода выводится из нормали плоского торца с наибольшим отверстием. Запасной вариант для геометрии без такого торца — наибольший размер глобального габарита вкладыша. Неоднозначную ось можно явно задать на пуансоне или вкладыше свойством `RevStrokeAxis` как глобальный вектор или строку X, Y, Z.
- Для G-CLEAR требуется положительное осевое перекрытие. Боковой зазор измеряется через `distToShape` между профилями в одном поперечном сечении, на 0,01 мм внутри зоны входа или ближе при малом перекрытии. При полностью заведённом пуансоне сечение берётся посередине перекрытия. При наличии замкнутого профиля отверстия проверяется, что профиль пуансона находится внутри него. Геометрическая точность для нулевого зазора и осевого перекрытия составляет 10⁻⁷ мм. Общий объём материалов даёт FAIL со ссылкой на G-COLL. Проверка относится к номинальной геометрии и одному сечению каждой пары.
- G-FEED проверяет путь в номинальной позе. Положительный общий объём с физическим телом блокирует путь. Путь должен подходить к вкладышу и, если в модели присутствует `hopper`, к бункеру на расстояние до 0,01 мм по уточнению ГК. Площадь считается по общим участкам граней вкладыша с объёмом подачи. При нескольких моделируемых путях в итог попадает наименьшая площадь. При сближении в пределах допуска без общей грани площадь равна нулю. Для связного свободного пути результат WARN до задания TECH числового порога `C-FEEDPATH-01.min_window_area_mm2`.
- `poses` — YAML вида «поза → роль или имя/метка группы FreeCAD → [dx, dy, dz]» в глобальных мм. По умолчанию `nominal` использует сохранённые положения. G-ENV объединяет габариты всех заданных поз, G-COLL проверяет каждую дискретную позу. Промежуточные и сервисные позиции задаются файлом поз.

## Воспроизведение

Из корня worktree в PowerShell.

```powershell
if (-not $env:REV_FREECADCMD) {
    $env:REV_FREECADCMD = 'E:/Tools/FreeCAD-1.1/bin/freecadcmd.exe'
}
$env:FREECAD_USER_HOME = Join-Path (Get-Location) 'ops/gates/.fc_home'
$env:FREECAD_USER_DATA = $env:FREECAD_USER_HOME
foreach ($variant in 'A', 'B') {
    $env:REV_GATE_ARGS = (@{
        model = "drawings/W02/output/W02-$variant-V1.FCStd"
        roles = 'ops/gates/roles/w02_legacy.yaml'
        criteria = 'ops/criteria/design_criteria.yaml'
        out = "ops/calibration/w02_${variant}_V1.json"
    } | ConvertTo-Json -Compress)
    & $env:REV_FREECADCMD ops/gates/geom_gates.py
    $LASTEXITCODE
}
```

`roles` принимает путь к YAML или JSON `null`. Поле `gates` ограничивает отчёт перечисленными гейтами. Полный набор запускается по умолчанию.

```powershell
& 'E:/Tools/Python313/python.exe' -B -m pytest -p no:cacheprovider tests/ops
& $env:REV_FREECADCMD tests/ops/test_geom_gates.py
$LASTEXITCODE
```

Python 3.13.17 и pytest 9.2.0 дали 2 PASS и 1 ожидаемый пропуск CAD-теста. Отдельный прогон FreeCAD подтвердил коды возврата, зазоры 0,1 и 0,8 мм у двух пар, нулевой зазор, выведенный из камеры пуансон, пересечение со вкладышем, площадь окна 108,8 мм², разрыв подачи, исключение операндов CAD-операций, WARN для оболочки, коллизию 200 мм³ и массу стального куба 7850 кг.
