# T-1.1 — приёмка ГК (25.11.2026)

Статус: **ACCEPT_WITH_NOTES как скрининговый результат.** Кругов: 1 (стоп, нет сети) + 2 (веб-поиск) + 1 круг исправлений.
Проверки: источники — Sonnet с вебом (8 DOI совпали с Crossref; точки Horabik, Križan рис. 5, Spirchez сверены с оригиналом; Li & Liu — платный доступ, точки не сверены); модель — Opus дважды (числа воспроизведены побайтно).

## Что принято
- Базовая кривая p(ρ) (степенной закон по 5 работам), K 0,45, μ 0,25, Янссен для 150 × 60.
- 166,7 МПа на торце → **≈ 1057 кг/м³ сразу после выхода**, для 1000 кг/м³ сразу после выхода нужно ≈ 132 МПа.
- **После стабилизации (~24 ч) холодный материал при 166,7 МПа даёт ≈ 977 кг/м³**; для 1000 нужно ≈ 179 МПа (диапазон по чувствительности 154–222 МПа).
- Работа уплотнения ≈ 31 кДж; подпрессовка ≈ 34 кН (цилиндр закладывать ≥ 70 кН).
- Цикл (копия X-1, перекрытие + акк. 5 л, 360 л/мин): 5,94 с при 166,7 МПа; **6,03 с при 179 МПа (Opus) — FAIL**.

## Замечания (не исправлялись, учитываются при решении)
1. Охват огибающей тавтологичен — огибающая строится из тех же опорных точек; нижняя граница держится на точке Horabik, пересчитанной через восстановление, противоречащее его же табл. 3.
2. Чувствительность к восстановлению 15/30 % в report.md посчитана без переподгонки (99,9 МПа — неверно). Корректно, с переподгонкой (Opus): осевое 10 / 15 / 30 % → 154 / 166 / 188 МПа; площадь 0 / 5 % → 175 / 182; K, μ низ/верх → 177 / 183; без Spirchez → 148; без Horabik → 222 МПа.
3. Цикл при 179,2 МПа исполнитель не прогнал (стоп-флаг); прогон Opus: 6,025 с, пик 284 бар.
4. Точки Matúš (472 кг/м³ при 159 МПа) физически невозможны — ошибка переноса, валидация по ним недействительна.
5. Одиночные точки весят как серия из 13 точек; «без одного источника» 148–222 МПа.
6. Spirchez: влажность оставлена 10 % по §2.1 статьи (закрытая матрица, рис. 8), а не 12 % — обосновано.
7. Стабилизация основана на одной паре Križan (−7,7 %, бук 2 мм, матрица 20 мм). Нагретая матрица (BP500-класс) может давать существенно больше: Dhamodaran при 60 °C — модель переоценивает давление на 70–90 МПа.
