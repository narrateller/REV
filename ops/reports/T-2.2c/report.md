# T‑2.2c — сравнение замков башмака подпрессовки

**Остановка по карточке на ручном расчёте.** Ни один из четырёх рассмотренных вариантов не прошёл входной отбор на FEA. Ближайший по циклу четырёхстоечный байонет потребовал бы прибавки **+81,80 кг** даже для балочной оценки жёсткости и ресурса днища. Его передняя опора также пересекает шибер.

## Нагрузка и методы

Интеграл профиля T‑1.2b на `x = 94,476…205 мм` даёт **1,224030 МН** при 300 бар, **1,285232 МН** при 315 бар и `x` равнодействующей **141,308 мм**. При 300 бар профиль начинается с 113,33 МПа и затухает с коэффициентом 0,0084 мм⁻¹. Для парных опор взята огибающая реакций 64/36 из T‑2.2b. Статика рассчитана при 315 бар. Номинальный экран FKM на `0 → 300 бар` использует `nσ = 1`, `kD = 15`, `j = 1,5`, `jG = 1,0/1,25` для поковки/литья, `Rz = 6,3 мкм` и влияние среднего напряжения по T‑1.7. [Профиль T‑1.2b](calc/T-1.2b/results.json) · [Методика FKM](https://vdma-verlag.com/publikation/rechnerischer_festigkeitsnachweis.html)

Для смятия применён проектный экран `0,60 Rp0,2` более мягкой детали. **480 МПа** для сменных пар требует гарантированного `Rp0,2 ≥ 800 МПа` сердцевины обеих вставок. Твёрдость поверхности 52–57 HRC и глубина SHD ≥ 6 мм взяты из требований T‑1.7d к кассете. Для оценок использованы профиль Герца, номинальное смятие, кромки R5 и выпуклость 0,10 мм. При усечении пятна оценка давления не определяет действительный пик. Каталог Schaeffler приводит 100–170 МПа для пульсирующего номинального давления закалённых шпоночных граней. Эта аналогия показывает, что проектный экран смятия требует отдельной проверки ресурса конкретной пары. ## Силовой путь, привод и компоновка

- **Сквозной блок.** Два цельных портала с расточенными направляющими, съёмный блок со шлифованными вкладышами, отдельный цилиндр Ø40/22 и парковочная направляющая. Один ход по оценке занимает 0,14 с при пике подачи 310 л/мин против 265 л/мин основного канала. Клин 4° самотормозится уже на одной поверхности при `μ = 0,10…0,15` (`φ = 5,71…8,53°`). Для двух поверхностей расчёт даёт 348…478 кН на ввод, 167…295 кН на вывод клина и 257…386 кН на вывод плоского блока под 315 бар. Переключение требует разгруженных рабочих граней. [Аналог клиновой фиксации US3353221A](https://patents.google.com/patent/US3353221A/en)
- **Рама T‑1.7.** Для благоприятной модели четыре колонны делят силу поровну, сечения пролёта Ø70 мм заделаны. Изгиб 471 МПа складывается с преднатягом 191 МПа. Номинальный отвод 36 мм за 12 мм хода штока сохраняет только оценку времени. Монтаж моста к существующим траверсам требует новой проверки мест ввода поперечной силы. [Рама T‑1.7d](design/frame.t17d.yaml)
- **Закрытая зона.** При проталкивании башмак держит до 292 кН при располагаемых 331 кН. Крыша в зоне конечного сжатия воспринимает все 1,285 МН. В модели крыша 120 мм дала бы 4,67 / 1,27 по изгибу и FKM, но требуется удлинённая заготовка камеры, главного и быстрых цилиндров и колонн. Даже оценка с полной подачей на дополнительный быстрый ход и вычетом двух движений кулачка даёт 6,388 с. Для вертикальной подпрессовки использованы схема Руфа и описание WEIMA. [T‑1.2b](ops/reports/T-1.2b/report.md) · [DE3333766C2](https://patents.google.com/patent/DE3333766C2/en) · [WEIMA TH 514/520](https://weima.com/en/briquetting-machines/th-514-520/)
- **Байонет.** Съёмные стойки с цельными пятами передают силу в днище. Муфты с тремя зубьями требуют шлифования сменных пар и синхронизации поворота 60°. От 12 мм хода штока получено по 0,08 с на запирание и отпирание при оценочной силе 14,6 кН на разгруженном механизме. При 315 бар момент трения на одной серии зубьев составляет 6,94…10,41 кН·м. Удержание одним цилиндром Ø125 как опорная оценка потребовало бы 1047 бар при 315 бар в главном контуре, а расчётное сжатие столба масла при 300 бар соответствовало бы 27,1 мм хода. [Аналог байонета EP0904918B1](https://patents.google.com/patent/EP0904918B1/en) · [T‑1.2b](ops/reports/T-1.2b/report.md)

В четырёхстоечном варианте учёт разного удлинения передней и задней стойки добавляет **0,064 мм** у края окна. Проверены 260 сочетаний высоты коробчатого днища и толщины двух рёбер. При Δ узла **+79,79 кг** лучший результат по жёсткости составил **0,503 мм**, FKM днища **0,918**. Вариант с днищем 150 мм и рёбрами 22 мм дал **0,498 мм** и **1,016** при **+81,80 кг**. В исходной компоновке точка `x=206, y=120, z=−90 мм` лежит внутри круглой пяты и закрытого шибера. Для двух стоек с тем же способом опирания проверены 945 сочетаний. В наиболее благоприятном сочетании из прошедших по перемещению одних стоек расчётное давление составило **528 МПа** при экране 480. [Огибающие и размерные предпосылки](metrics.json) · [Геометрия шибера](design/slide_gate.t17d.yaml)

## Масса машины и решение по D‑GK

Расчётная база **4942,65 − 180,22 кг** плюс новый узел. H2 T‑2.2 добавлен отдельной вилкой **5…18 кг**. Со сквозным блоком получается 4976,12…4989,12 кг, с опорой на раму 4971,02…4984,02 кг. С удлинённой камерой плюс удлинение цилиндров и колонн требуется снять 118,72…131,72 кг. Байонет в исходной геометрии требует снять 10,34…23,34 кг, с днищем 150 мм и рёбрами 22 мм — **29,45…42,45 кг** по D‑OP‑10. [База и H2](ops/reports/T-2.2/GK_review.md) · [Разбивка](metrics.json)

**Проект записи для ГК.** «По D‑OP‑13 пункт D1 о замке башмака остаётся открыт. Рассмотренные исполнения T‑2.2c к выпуску КД не допускать. Для продолжения по байонету согласовать компоновку передней опоры вне огибающей шибера и допустимую массу узла до назначения КЭ‑модели». FEA, полный VDI 2230 и проектный YAML ожидают выбора исполнения. Открытые вопросы после нового отбора — распределение нагрузки зубьев, давление и износ закалённой пары, остаточная сила отпирания и доступ к сменным деталям при сборке.

G‑PFACE **168,889 МПа**, G‑DOSE **306 мм**, G‑CYCLE **5,824 с** прошли при повторном прогоне на `params.t21`. Этот набор относится к базовому циклу. Windows запретила запись в существующие файлы `calc/T-2.2c` и `gates.t22c.json`. Два прогона исправленных расчётов во временной копии дали одинаковый результат, а новый отчёт гейтов побайтно совпал с существующим. Числа и резервную копию правок сохранил в двух корневых JSON.
