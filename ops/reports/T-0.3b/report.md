## Модель гейта

Одноимённые смежные фазы образуют группу. `start_delay_s` задаёт момент команды от начала группы. Одновременные команды гидравлики делят одно переключение 0,10 с, отложенная команда имеет своё переключение. `continues` запускает следующую полосу того же непрерывного движения. Группа завершается по последней фазе, включая выдержки. Для `actuator: none` время задаётся только `dwell_s`. В калибровочных YAML выдержка 0,30 с и сброс 0,25 с уже включают по 0,10 с на клапаны согласно эталонной циклограмме.

Шаг движения ≤5 мс с отсечками на запуске, завершении движения и исчерпании масла аккумулятора. Давление насоса равно наибольшему давлению среди активных запросов на движение. Насос делит доступную подачу по порядку YAML. При суммарном дефиците аккумулятор дополнительно питает разрешённые ветви в том же порядке и освобождает часть подачи насоса. При простое зарядка идёт на заданном давлении с учётом `round_trip_eta`. Дозарядка по окончании цикла начисляется отдельной фазой для остатка. Гейт проверяет ход в фактическом порядке движений, возврат, наличие и конфигурацию фазы прессования, давление, скорости и мощность. Пересекающиеся движения одного привода вызывают `InputError`.

Числовое `speed_mm_s` задаёт скорость, которую проверяет `requested_speeds_met`. При `speed_mm_s: pump` скорость определяется доступной подачей. Необязательное `max_speed_mm_s` ограничивает её сверху с учётом суммарной подачи насоса и аккумулятора. Меньшая скорость допустима. Числовое `speed_mm_s` вместе с `max_speed_mm_s` вызывает `InputError`.

Во всех сценариях насос рассчитан на 360 л/мин и 30 кВт. Для баллона 5 л с предзарядом 28 бар и диапазоном 38–75 бар по газовой модели эталона доступно 1,534 л масла. Предел отдачи 150 л/мин. Давление зарядки 78 бар учитывает 3 бар потерь в линии. `round_trip_eta: 1` соответствует объёмному балансу эталона. В калибровках весь объём восстанавливается при подаче дозы. Команда закрытия шибера отсчитана от начала группы возврата по геометрическому просвету 20 мм для X-1 и 69 мм для T-1.2b A при 250 мм/с, с учётом 0,10 с переключения возврата. Длительности в секундах включают переключения. Столбцы `Δ полос` показывают добавку относительно непрерывного профиля давления при прочих условиях гейта. Для A обе подачи имеют одинаковые гидравлические фазы.

Вклад полос рассчитан заменой постоянного давления каждой полосы на `motion.pressure_bar(x)` независимой модели с неизменными площадью поршня, характеристикой насоса и ограничениями скорости. Для одиночного движения время по кривой интегрировано по 4000 средним точкам как `Σ Δx × max(1 / speed(x), area / Q_pump(p(x)))` в СИ. Для группы возврата исходные давления постоянны на каждом участке, включая кулачок A. Границы полос взяты из генератора T-1.2b, давление в каждой полосе — максимум профиля на её участке. [Правила разбиения](calc/T-1.2b/make_params_t12b.py)

Полосы давления добавили около +0,3 с относительно эталона (0,297 с для X-1 и 0,337 с для A). Отсутствие динамики разгона насоса и сжимаемости масла в гейте вместе с отличиями в стратегии разряда и моментах срабатывания даёт остаток около −0,3 с (−0,309 и −0,316 с после вычета вклада полос). Например, открытие шибера при постоянной нагрузке занимает на 0,035 с меньше в гейте. При закрытии шибера эталон ждёт фактического положения пуансона, а гейт использует заданное время команды. Для других циклограмм величины этих эффектов могут отличаться.

## Как описывать циклограмму для T-1.4

Фрагмент конца цикла X-1. Три движения используют одну группу, а подача дозы начинается после её завершения.

```yaml
drive:
  accumulator:
    usable_oil_L: 1.534
    max_flow_L_min: 150
    min_delivery_pressure_bar: 38
    charge_pressure_bar: 78
    round_trip_eta: 1
    recharge_when_idle: true
cycle:
  - {name: return, group: return_and_close, actuator: main_cylinder,
     direction: retract, stroke_mm: 210, pressure_bar: 24.23,
     speed_mm_s: pump, max_speed_mm_s: 250, regeneration: false,
     dwell_s: 0, use_accumulator: true}
  - {name: gate_close, group: return_and_close, actuator: slide_gate,
     start_delay_s: 0.18, direction: extend, stroke_mm: 70, pressure_bar: 23.35,
     speed_mm_s: pump, max_speed_mm_s: 250, regeneration: false, dwell_s: 0}
  - {name: pre_up, group: return_and_close, actuator: precompaction,
     direction: retract, stroke_mm: 257.4074074074074, pressure_bar: 20.47,
     speed_mm_s: pump, max_speed_mm_s: 650, regeneration: false, dwell_s: 0}
  - {name: feed, actuator: none, dwell_s: 0.50}
```

`start_delay_s` отсчитывается от начала группы до команды шиберу. Движение шибера начинается после собственного переключения клапана. Для команды «по положению» пересчитывайте задержку при каждом изменении подачи или скорости. Используйте время достижения нужного просвета с учётом переключений и деления подачи между приводами.
