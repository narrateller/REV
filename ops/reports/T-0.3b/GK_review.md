## Правила применения (до T-0.3c)
1. **Прессование, выдержка и подача — без перекрытия.** Фаза `press: true`, фаза `none` выдержки и сброса после прессования, фаза `none` подачи дозы — не в общей группе с движением другого привода. Иначе выдержка прячется за ходом (Sonnet воспроизвёл ложный PASS 2,09 с). ГК проверяет это вручную на каждом params до T-0.3c.
2. **Точность гейта ±0,15 с.** Совпадение калибровки частично случайное: полосы давления +0,3 с, остаток −0,3 с вычислен вычитанием. Поэлементно ошибки до ±0,075 с. Если запас до 6,0 с меньше 0,3 с, итог подтверждается эталонным симулятором (`calc/T-1.2b/x1_calc.py`, непрерывный профиль давления). Полосы — по правилам `calc/T-1.2b/make_params_t12b.py`.
3. **Порядок фаз в группе.** Фаза `pump` без `max_speed_mm_s` забирает подачу по порядку YAML. Порядок задаёт приоритет, это должно соответствовать гидросхеме (T-1.5).
4. `start_delay_s` для действий «по положению» пересчитывать при смене подачи или скорости.
