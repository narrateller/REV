# T-0.2 · Расчётные гейты и область изменений

G-PFACE, G-DOSE, G-CYCLE и G-SCOPE выдают отчёты `rev.gate_report/1`. Расчётный CLI поддерживает `--gates` и выдаёт `ERROR` при ошибках в именах единиц, строках с единицами и недопустимых значениях. Число в другом масштабе под верным именем выявляется при нарушении физического порога. Пороги загрузки, давления, силы и мощности взяты из критериев v1. Добавка 0,1 с за переход между фазами взята из карточки. [Схема](design/params.schema.yaml) · [Критерии](ops/criteria/design_criteria.yaml) · [Карточка](ops/tasks/T-0.2.yaml)

## Формулы и допущения

- **G-PFACE.** Два размера сечения сравниваются с допуском ±1 мм. Давление для порога равно `F_ном / A_камеры`, где `A_камеры` — площадь внутреннего просвета. Доступная сила в Н равна `0,1 × p_бар × n × π × D_мм² / 4 × η`. При давлении настройки клапана выводятся справочные значения силы и давления по просвету и торцу пуансона. Для W02-04 тот же оценочный КПД цилиндра 0,937 даёт 71,93 МПа по торцу при 315 бар. Идеальная оценка аудита при КПД 1 составляет 76,8 МПа. [Аудит §3.2](docs/AUDIT_OPUS_REPORT.md#32-удельное-давление-на-материал--главный-технологический-дефект)
- **G-DOSE.** Рыхлый объём `V_рыхл_л = 1000 × m_кг / ρ_насып_кг_м³` проверяется при 90 и 160 кг/м³. Для порогов используется прежняя консервативная формула `s_потр = L_засыпки + s_выталк`, где `L_засыпки_мм = (m_кг / ρ_передачи_кг_м³) × 10⁹ / A_глав_мм²`. Справочный минимум `s_мин = s_подвод + max(0, L_засыпки − L_под_нагрузкой) + s_выталк` использует ту же площадь камеры для расчёта `L_под_нагрузкой` из плотности под нагрузкой. Отчёт показывает отношения паспортного хода к обеим оценкам. Для W02-04 приняты прямая засыпка при 90 кг/м³ и ход выталкивания 110 мм по верхней длине C-PROD-02. Подвод принят равным нулю для оценки снизу, плотность под нагрузкой заменена плотностью после выхода 1000 кг/м³. [Аудит §3.1](docs/AUDIT_OPUS_REPORT.md#31-доза-камера-ход) · [Критерии](ops/criteria/design_criteria.yaml)
- **G-CYCLE.** Объём каждой фазы `V_л = A_мм² × s_мм / 10⁶`. При прямом ходе используется площадь поршня, на обратном — кольцевая, при регенерации — площадь штока. Подача насоса ограничена `min(Q_max, 600 × P_двиг_кВт × η / p_бар)`. В таблице фаз пиковая мощность всего потока в пересчёте через КПД равна `p_бар × Q_сумм_л/мин / (600 × η)`. Для проверки пика привода формула использует расход насоса, включая фазу заряда аккумулятора. Энергия двигателя `E_кДж = p_бар × V_насоса_л / (10 × η)`. Аккумулятор ограничен давлением, расходом и запасом масла. Выдержки считаются без расхода. Модель опускает разгон, переходные процессы, утечки и потери сверх заданного КПД.
- **Финальное прессование и установленная мощность.** В цикле требуется фаза `press: true` на прямом ходе главного цилиндра без регенерации. Для каждой такой фазы проверяется сила по суммарной площади поршней с КПД цилиндра. Предел установленной мощности составляет 34,2 кВт, отсутствие значения даёт WARN при успешных остальных проверках. В W02-04 при 100 бар, 180 л/мин и КПД привода 1 использованы два расчётных перемещения. Финальная фаза и установленная мощность для них неизвестны. [Аудит §3.3](docs/AUDIT_OPUS_REPORT.md#33-цикл-расход-масла-мощность)
- **G-SCOPE.** Проверяются изменения в `main...HEAD`, индексе, рабочем дереве и неотслеживаемых файлах. SHA-256 защищённых файлов сверяется с общим предком `main` и `HEAD`. Изменения индекса или HEAD учитываются и при восстановленном содержимом на диске. `allow_protected` явно снимает защиту для совпадающих файлов `ops/gates/`. Защита `ops/criteria/` действует при любых шаблонах карточки. Отчёт перечисляет игнорируемые файлы Git. Файлы вне разрешённых путей дают WARN, за исключением `__pycache__`, `.pytest_cache` и `*.pyc`. Сведения об effort берутся из `--meta` или `meta.json` в worktree.

**Вопрос для TECH на шаге 1.** Какие плотности принять при передаче засыпки и под финальной нагрузкой, где расположен пуансон в исходном положении и какой ход нужен для выхода брикета через открытый шибер? По этим данным можно проверить условие `s_подвод ≤ L_под_нагрузкой`, при котором прежняя формула даёт верхнюю оценку относительно справочного минимума.
