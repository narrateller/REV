# T-2.2d — решение ГК (26.11.2026)

**Вердикт: нагрузка, крыша X = 15 мм, блокировка дозы — ACCEPT; байонет — HOLD (ручной отсев, 2 круга исчерпаны).**
Фактический исполнитель: bos high (оба круга; круг 1 — автоматическое переключение раннера с alm по лимиту).
Проверка: нагрузка воспроизводит независимый расчёт Opus из разбора T-2.2c (1,069 / 1,130 МН при K 0,60, μ 0,30 / 0,25) — совпадение; цикл — гейт ГК на params.t22d.

## Гейты (ГК, критерии v4, params.t22d)
- G-PFACE 168,89 МПа, G-DOSE 321 мм, G-CYCLE 5,929 с — PASS (запас 21 мс до 5,95); G-SCOPE PASS по путям.
- params.t22d против t21: только ход 306 → 321, рабочий 291 → 306, длина 265 → 280, перебег 76 → 91 от прежней кромки окна.

## Принято
- Нагрузка (Janssen, длина под нагрузкой 89,4 мм, сетка K 0,35–0,60 × μ 0,20–0,30, два метода совпадают до 2,3e-10 Н): без крыши 1,196 / 1,255 МН (300 / 315 бар); определяет K 0,60, μ 0,20.
- Крыша X = 15 мм: башмак 1,034 / 1,086 МН, крыша 169 кН; шибер +15 мм (грань x = 220), ход 321 мм, рама 1166 → 1181 мм, ГЦ 647 → 662 мм; +15,05 кг. Цикл: реалистичный 5,624 с, пессимистичный 5,987 с, гейт 5,929 с.
- Блокировка дозы: уставка ≤ 0,853 кг при точности ±5 %, весовой контроль каждой порции перед главным ходом.

## Не принято — байонет (HOLD)
- 90 720 сочетаний: при FKM ≥ 1,10 лучший Δh = 0,531 мм (цель карточки 0,5), узел +58,43 кг (цель +40). Масса машины 5016 кг, с H2 T-2.2 5021–5034 кг.
- Привод замка: поворот муфт 80 мс против 40 мс кулачка — при последовательном переключении больше запаса гейта 21 мс.
- Контакт зубьев 415 / 480 МПа (экран), ресурс пары не подтверждён; доля зуба до 40 % силы стойки при разбросе посадки 3–8 мкм.
- FEA не выполнялась (стоп по ручному отсеву).

## Решение
D-GK-10 (нагрузка, X 15 мм, блокировка дозы, params.t22d — действующий эквивалент гейта). Продолжение по замку — решение ГК (см. D-GK-10).
