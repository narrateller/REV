# T-0.3c — мощность привода и защиты G-CYCLE

G-CYCLE применяет C-PWR-01 v3 по D-OP-07. Номинал двигателя и средняя мощность на валу за цикл ограничены 30 кВт, RMS — 30 кВт, заявленный и расчётный пики — 40 кВт, установленная мощность — 34,2 кВт. При давлении `p > 0` подача насоса в л/мин равна `min(pump_max_flow_L_min, 600 × peak_kW × η / p)`, где `p` задано в бар, а `η` — КПД привода из параметров. При `p = 0` доступна паспортная подача. Если `drive.peak_kW` пропущен, используется `motor_kW`. [Решение D-OP-07](DECISIONS.md) · [Критерии v3](ops/criteria/design_criteria.yaml) · [Схема параметров](design/params.schema.yaml)

## Расчёт мощности

Для интервала длительностью `Δtᵢ` получаем мощность на валу `Pᵢ = pᵢ × Qᵢ / (600 × η)` в кВт. Для параллельных движений на каждом шаге до 5 мс берётся давление в общей линии и суммарная подача насоса. Зарядка аккумулятора учитывается по мощности насоса в интервалах зарядки. В остальных паузах, включая переключения клапанов, используется `drive.idle_kW`. Значение по умолчанию 0 кВт задано карточкой задачи. В калибровках поле отсутствует, поэтому 0 кВт здесь — расчётное допущение. [Карточка задачи](TASK.md) · [Реализация](ops/gates/calc_gates.py)

- `P_avg = Σ(Pᵢ × Δtᵢ) / T`
- `P_RMS = √(Σ(Pᵢ² × Δtᵢ) / T)`
- `P_peak = max(Pᵢ)`

В `x1_overlap` цикл занимает 5,853771 с. Из них 1,167177 с приходятся на интервалы с `idle_kW = 0`. Энергия на валу равна 105,111350 кДж, интеграл квадрата мощности — 2 725,771570 кВт²·с. Отсюда средняя мощность `105,111350 / 5,853771 = 17,956177` кВт, RMS `√(2725,771570 / 5,853771) = 21,578779` кВт. Максимальный шаговый пик — 30,000000 кВт. [Параметры X-1](ops/calibration/x1_overlap.params.yaml) · [Метрики](metrics.json)

## Защиты циклограммы

- `press: true` требует отдельной группы. Фаза `actuator: none` в группе с движением требует `overlap_allowed: true`. Нарушение вызывает `InputError`. При явном разрешении гейт выдаёт предупреждение и показывает `overlap_time_s` для фазы. Одновременные движения считаются в этом времени один раз.
- `max_speed_mm_s` допускается до 1000 мм/с включительно. Несколько движений `pump` без этого ограничения в одной группе вызывают предупреждение о приоритете подачи по порядку YAML.
- На границе групп для `continues` применяется абсолютный допуск 10⁻⁹ с.

## Ограничения и открытые вопросы

Модель использует постоянный КПД, заданные полосы давления и заданные задержки команд. При смене подачи следует пересчитать задержки команд, привязанных к положению. Ревью T-0.3b указывает точность калибровки ±0,15 с и требует сверки с непрерывной моделью, если запас до 6 с меньше 0,3 с. Для будущих конфигураций с `peak_kW > motor_kW` входными данными остаются подтверждённые пиковая способность привода и фактическая мощность холостого хода. [Ревью T-0.3b](ops/reports/T-0.3b/GK_review.md)
