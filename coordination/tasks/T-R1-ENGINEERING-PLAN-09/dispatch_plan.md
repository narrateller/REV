# T-R1-ENGINEERING-PLAN-09 — источники физических входов W02

Предыдущая эстафета завершена. Условная КД W02 принята в области [вердикта R5](../../completions/T-R5-DRAWINGS-VERIFY-01/completion.json).
В [акте R4](../../completions/T-R4-DRAWINGS-01/completion.json) открыты восемь позиций.
Для 42 физических состояний сохраняется `BLOCKED_INPUTS`, для физических §§4/5/6 — `NOT_RUN`.

| Приоритет | Роль | Следующий результат и условие постановки |
| --- | --- | --- |
| P0 | R1 | После свежего claim сверить открытые позиции с пакетом R2, каталогом W02 и журналами 42 состояний. Для каждой позиции указать доступный источник или требуемый документ, ответственного и критерий пригодности. |
| P0 | R2 | Если доступен новый источник, подготовить отдельный аудит границ T/U, свойств сырья, профилей давления и фазовых нагрузок в применимой области. Сохранить ревизии, единицы, условия применимости и неопределённость. |
| P0 | R4 | После подтверждения входов назначить аудит силовой геометрии, опор, материалов, допусков и данных о соединениях. Связать их с CAD W02 и случаями R3. |
| P1 | R3 | После подтверждения нагрузок, реакций, геометрии и критериев запланировать расчёт по случаям §§4/5/6 с явным допуском каждого состояния по входам. |
| P1 | R5 | После появления нового инженерного результата проверить точный SHA, воспроизводимость и заявленные критерии. |

Первой назначается текущая задача R1. Последующие задачи получают новые ID после проверки
источников, статусов и claims в актуальном `main`. Для отсутствующих значений фиксируются
`UNKNOWN`, `null` и причина. Физические испытания и выпуск КД требуют отдельного решения человека.
