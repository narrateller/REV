# T-R2-INPUTS-01 — проект численных входов и требований

BP500 задаёт исходные ориентиры для адаптации площадки под брикетировочный пресс. Входы привязаны к `053f6e3d475df5875ce38bfce6579dac46ddf553`. Материалы предназначены для обследования площадки, постановки расчётов и подготовки исходных требований. ТЗ и архитектура REV имеют статус `NOT_APPROVED`, G1 открыт. ## Передача R4 и открытые входы

Для каждого `S42-001`–`S42-042` машинный аудит фиксирует `BLOCKED_INPUTS`, физическое выполнение `NOT_RUN`, недостающую фазовую нагрузку и граничные условия. Неопределённые входы сохраняют `value: null` и конкретную причину. Условный screening `CALCULATED_ASSUMED` относится к ранее сохранённой постановке. [Физические блокеры R3](../../../cae/cases/T-R3-42-STATES-01/case_audit.json) · [Условные статусы](../../../params/T-R3-42-STATES-01-status.json)

- Для нагрузки зафиксировать вариант, фазу, координаты и знаки сил и моментов, начальные и промежуточные позы. Принять сырые измерения и документировать условия заполнения, удержания, выдачи и переходов. В расчётах проверить балансы массы, сил и моментов и совместимость фаз по времени и ресурсу.
- Для силовой геометрии R4 требуются датумы, контакты, опоры, эксцентриситеты, свободные длины и реальные сечения. Для соединений требуются направления усилий, геометрия, свойства материалов, крепёж и допускаемые значения с источником. Для КД также нужны посадки, допуски, проверяемые стыки и спецификация.
- Для входной приёмки привязать каждое полученное значение к партии или конфигурации, фазе, единице, методу, ревизии, допуску и неопределённости. Для фактической площадки приложить обмеры, параметры ввода и проверку основания. Верификация физических величин и решение по испытаниям выполняются по отдельным основаниям.

Следующая по эстафете `T-R4-DRAWINGS-01` ожидает готовую инженерную базу. Журнал проверок R2 относится к документальному результату и воспроизводимости. [Манифест R4](../T-R4-DRAWINGS-01/task.json) · [План R1](../T-R1-ENGINEERING-PLAN-06/dispatch_plan.md)

## Воспроизведение

```text
python coordination/tasks/T-R2-INPUTS-01/verify_output.py --check-git
python scripts/check_registry.py --check-git
python -m unittest discover -s tests -v
python verify_output.py --check-git
```

Верификатор пакета читает исходные Git blobs по закреплённому SHA, проверяет фактические байты BP500 PDF, воспроизводит аудит и сверяет сохранённые выходы. Числа в строках площадки сверены визуально со страницами 3–4. Скрипт проверяет хэш источника, метаданные и преобразования единиц.
