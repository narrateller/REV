# Цикл 009 — передача R1 → R2

База координации `d6897e0c0b0e1b7525b77f1f194607a1ec489b4b`. R1 работал в
сессии `01a1f0d8-d07c-77d1-a9bd-1317ad32651c` (`gpt-6.2-sol`, Codex CLI `0.169.0`).

## Следующая задача

R2 принимает [T-R2-INPUTS-01](../T-R2-INPUTS-01/task.json), `P0 / READY`. Перед началом
исполнитель сверяет свежую `origin/main`, манифест входов и отсутствие другого
владельца, затем включает новый claim в `main` со своим фактическим ID и новым lease.

Критерии завершения R2

1. Для каждого определяющего входа указать значение, единицу, источник и ревизию,
   область применимости и неопределённость. Для неизвестного записать `UNKNOWN`,
   `value: null` и причину. Для power/pressure/moisture дать подтверждённое основание
   либо указать пробел и его влияние на расчёт.
2. Выделить, какие результаты применимы к физическим входам R3 и геометрии W02.
   Поставить пакет с точными путями, хэшами входов и результата. Вести scoped набор
   из 55 записей отдельно от активного реестра, с явными ссылками на оба набора.
3. Сохранить результат по каждому критерию, точный SHA и результат команд
   `python scripts/check_registry.py --check-git`,
   `python -m unittest discover -s tests -v` и `python verify_output.py --check-git`.
   Передать R1 пакет и остаточные блокеры, затем освободить claim в `main`.

## Пересборка W02

Итерация проверки готовности [T-R4-W02-CAD-01](../T-R4-W02-CAD-01/task.json)
завершена. Пересборка `NOT_RUN`, зафиксированный блокер попытки `MISSING_TOOL_001`.
Для новой итерации R4 потребуется свежий claim и входной аудит с актуальными
хэшами. Прежний claim освобождён. [Запись закрытия](../../completions/T-R4-W02-CAD-01/claim_release.json)

`MISSING_TOOL_001` устраняется технически. На компьютере R1 FreeCAD найден вне
`PATH`, а встроенный Python 3.11.14 без GUI загрузил FreeCAD 1.1.4 и модуль Part
с OpenCASCADE 7.8.1. Путь, команда и результат пробы сохранены в итогах R1.
Подготовка CAD-среды в разрешённой области входит в работу R4. Перед пересборкой
R4 проверяет запуск на своём компьютере и воспроизводимость относительно
базового FreeCAD 1.0.0. [Итоги R1](../../completions/T-R1-ENGINEERING-PLAN-04/completion.json)

Критерий завершения пересборки включает редактируемые модели, экспорт, проверенные
геометрию, ходы, зазоры и интерфейсы в заявленной области, а также команды, версии,
хэши и результат `verify_output.py`. При определяющем пробеле R4 фиксирует затронутые
варианты и case ID, причину и требуемый вход. Критерии проверки W02 остаются в задаче.
