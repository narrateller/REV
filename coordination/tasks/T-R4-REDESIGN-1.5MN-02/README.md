# T-R4-REDESIGN-1.5MN-02 — контакт ключей затвора B

**R4 · P0 · READY**. Перед инженерной работой принять свежий claim в
`main` и провести входной аудит по [карточке задачи](task.json).

## Исходный отказ и критерий

В закрытой ветви ключей B при статическом заклинивании 315 бар приложены
к поршневым полостям обоих цилиндров при нулевом обратном давлении.
Осевое усилие источника составляет 3,093 МН. При смещениях
`|e_y| = 75 мм` и `|e_z| = 30 мм` R3 получил локальный пик 224,94 МПа
и запас 1,111 в области `CALCULATED_ASSUMED`.
[Инженерный отказ R3](../../../cae/cases/T-R3-FORCE-CALC-02/engineering_failure_note.md)

Цель второй итерации — запас по контакту ключей и сопряжённых опор
**≥ 1,5 при 315 бар**. Сопоставить варианты увеличения сечения и контактных
площадок ключей, добавления ряда ключей, изменения материалов или геометрии
соединения. Проверить пиковое местное давление при той же границе нагрузки
и обосновать разделение реакций между площадками с учётом жёсткости,
эксцентриситетов, допусков и зазоров. Для определяющей контактной пары
использовать допустимое давление, подтверждённое входами принятой постановки.

## Результат для передачи

Поставить редактируемую CAD-сборку затронутых вариантов B, геометрию
контакта, интерфейсы и допуски, обоснование материала, воспроизводимый
расчёт пикового давления и манифесты с SHA-256. Передать R1 точный SHA
и описать изменения входов для повторного расчёта R3 и независимой
проверки R5.

Зазор направляющих при рассогласовании цилиндров и аварийный реверс
одной ветвью остаются открытыми по акту R3. Физические входы
`BLOCKED_INPUTS`, физические §§4/5/6 `NOT_RUN`. Выпуск КД заблокирован
инженерным отказом. Выпуск в производство требует решения оператора.
