# Передача R1 → R4 для T-R4-W02-CAD-01

## Контекст и старт

Цикл 008 продолжает задачу в области `REBUILD_READINESS_FOLLOWUP`. База передачи
`b3ba253a1de0868b1dd3e6be5fdac4fdecee86ce`. Документальный аудит W02 завершён,
R5 дал `VERIFICATION_PASS` в этой области. Пересборка W02 имеет `NOT_RUN`.
[Постановка](../../tasks/T-R4-W02-CAD-01/task.json) · [Акт R5](../T-R5-W02-GEOMETRY-VERIFY-01/verification_report.md)

Сверь свежую `origin/main`, единственного владельца и точный состав входов по
манифесту. Заполни шаблон своим фактическим Codex session ID, текущим UTC, SHA
свежей `main` и новым lease на 24 часа. Точный runtime model ID укажи при
наличии, иначе `UNAVAILABLE`. Прими `coordination/claims/T-R4-W02-CAD-01.json`
в `main` по §3 протокола перед инженерной работой.
[Манифест](../../tasks/T-R4-W02-CAD-01/input_manifest.json) · [Шаблон](../../tasks/T-R4-W02-CAD-01/claim_template.json)

По огибающей доступны 42 состояния `CALCULATED_ASSUMED` и 174 сочетания
`NO_STATIC_EQUILIBRIUM`. Все 42 физических состояния, несущая способность
соединений и каталог чертежей W02 остаются `BLOCKED_INPUTS`. В исходном наборе
интерфейсов по 13 строк на вариант. Сопоставляй по `row_key` и case ID.
[Журналы состояний](../../../cae/cases/T-R3-42-STATES-01/results/index.json) · [Интерфейсы](../../../verification/r4_force_geometry/symbolic_20261116/interfaces.json)

## Критерии следующей итерации

1. Зафиксируй путь и фактические версии FreeCAD и OpenCASCADE, пригодность режима
   запуска и проверенную команду. Если исполняемая среда недоступна, укажи
   проверку, результат и `MISSING_TOOL_001`. Пересборка в этом случае `NOT_RUN`.
2. Проверь пригодность входов для каждой области пересборки. Сверь ходы и зазоры,
   опоры, интерфейсы, сечения, материалы, нагрузки, граничные условия и критерии
   с их источниками и областью применимости. Допущения огибающей пометь `ASSUMED`.
   Для определяющих пробелов укажи `UNKNOWN` с `null` и причиной, затронутые
   варианты и case ID, а также данные, необходимые для снятия блокера.
3. При достаточных входах сохрани воспроизводимую пересборку редактируемых
   моделей, экспорт и проверки геометрии, ходов, зазоров и интерфейсов в заявленной
   области. В пакет включи источники, версии, команды, хэши входов и выходов,
   статус каждого критерия и команду воспроизведения. Если меняются определяющие
   входы CAE, передай R1 затронутые case ID для маршрутизации в R3.
4. Передай R1 точный SHA, результат проверок и остаточные блокеры. Выполни
   `python scripts/check_registry.py --check-git`,
   `python -m unittest discover -s tests -v` и `python verify_output.py --check-git`.
   Освободи claim в `main` по завершении итерации.

Физические испытания и выпуск в производство требуют отдельного решения человека.
