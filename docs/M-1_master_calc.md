# M-1 — мастер-расчёт ГК (шаг 1)

Статус: **REVIEW** (предварительный, 25.11.2026). Фиксируется только на D1 после X-1 (независимый пересчёт) и T-1.1 (кривая уплотнения).
Код: `calc/M-1/m1_calc.py` (модель, вилки), `calc/M-1/make_params.py` → `design/params.m1.yaml`.
Основание: D0 (закрытая камера 150 × 60, вертикальная подпрессовка, один соосный главный цилиндр, шибер), `ops/criteria/design_criteria.yaml` v1.

## 1. Силовая схема

Замкнутый силовой контур: главный цилиндр → рама (4 преднапряжённые стяжки или сварная плита-рама, решает шаг 2) → корпус камеры со сменными вкладышами → шибер-противодержатель. Сила прессования не выходит на фундамент; фундамент несёт только вес и реакции разгона масс.

Расчётная нагрузка силового пути (C-STR-01) — давление настройки предохранительного клапана: **p_relief = 300 бар → F = A·p = 0,06158 · 30 МПа = 1,85 МН** (идеально, без η). Давление на торце при этом 205 МПа.

## 2. Сила и главный цилиндр

| Величина | Значение | Комментарий |
|---|---|---|
| Сечение брикета = сечение камеры | 150 × 60 = 9 000 мм² | C-PROD-01, правило C-PFACE-01 |
| Номинальная сила | **1,52 МН** | 166,7 МПа · 9 000 мм² = 1,5003 МН; ровно 1,5 МН даёт 166,67 < 166,7 (неточность округления в критериях, гейт её ловит) |
| Главный цилиндр | **Ø280 / шток Ø200**, A = 61 575 мм², φ = 2,04 | Ø280 — дополнительный ряд ISO 3320 |
| Давление для 1,52 МН (η = 0,95) | 260 бар | p_work = 270 бар → F = 1,58 МН (запас 4 %) |
| p_relief | 300 бар | ≤ 315 (C-HYD-01) |

Вилка: Ø250 даёт 322 бар для 1,5 МН — **недопустимо** (> 300). Ø320/220 даёт 196 бар, но +22 % масла и цикл 6,1 с. Ø280 — единственный вариант, проходящий и давление, и цикл с запасом.

Шток Ø200 выбран по циклу: малая штоковая полость ускоряет возврат, большая площадь штока — дифференциальный подвод. Продольная устойчивость при ходе 230 мм не лимитирует (λ ≪ 20).

## 3. Доза, подпрессовка, ходы

Доза 0,83 кг (C-PERF-01). Плотность в камере под нагрузкой ρ_die = 1180 кг/м³, упругое осевое восстановление 10 % (обе величины — до T-1.1).

| Величина | Значение |
|---|---|
| Длина брикета в камере / после выхода | 78 / 86 мм (C-PROD-02: 40–110 ✓), ρ после выхода 1073 кг/м³ (C-PROD-03 ≥ 1000 ✓) |
| Окно подпрессовки (план) | 150 × 200 мм; канал под ним 150 × 60 × 200 мм = 1,8 л |
| Плотность после подпрессовки | 0,83 / 1,8 л = **461 кг/м³** |
| Высота рыхлой засыпки над каналом | 307 мм при 90 кг/м³; 173 мм при 160 кг/м³ |
| Ход подпрессовки | 317 мм (засыпка при 90 кг/м³ + 10 мм) |
| Сила подпрессовки | p(461) = 3,1 МПа × 1,3 = 4,0 МПа × 0,03 м² = **119 кН**; Ø100 → 160 бар |
| Главный ход: прессование + выталкивание | (200 − 78) + (78 + 10) = **210 мм потребно**; принят ход 230 мм (1,10 ≤ 1,3, C-DOSE-01 ✓) |

**Дозирование.** Камера подпрессовки — объёмная. При постоянном объёме масса дозы зависит от насыпной плотности (90…160 кг/м³ → разброс ×1,8). Поэтому доза дозируется **по массе или по силе/положению подпрессовки**: подача идёт, пока подпрессовка не достигнет заданного положения при заданной силе. Длина брикета при этом плавает в пределах C-PROD-02. Задача T-1.2.

## 4. Работа уплотнения, циклограмма, мощность

Кривая p(ρ) (давление на торце пуансона против средней плотности, трение о стенки включено) — **заглушка порядка величины** до T-1.1: 461 → 3 МПа, 600 → 8, 800 → 30, 1000 → 80, 1180 → 166,7 МПа (лог-линейно).

Работа уплотнения одной дозы: ∫p·dV = **32 кДж** (вилка ×1,3 → 42 кДж). Средняя мощность на материал ≈ 5–7 кВт, то есть мощность не лимитирует. **Лимитирует подача насоса на холостых и малонагруженных ходах.**

Привод: регулируемый насос с регулятором мощности, двигатель 30 кВт (C-PWR-01), η = 0,85, **Q_max = 360 л/мин** (излом регулятора мощности при ~42 бар). Дифференциальная схема на подводе (до 120 бар на площади штока) и на выталкивании. Масло за цикл 18,4 л.

| Фаза | t, с (модель ГК) |
|---|---|
| Подпрессовка вниз (сила растёт к концу хода) | 0,43 |
| Прямой ход главного: подвод + уплотнение (из них высокое давление 0,93) | 1,52 |
| Выдержка / разгрузка | 0,20 / 0,15 |
| Открытие шибера | 0,25 |
| Выталкивание (дифф.) | 0,55 |
| Возврат главного | 1,06 |
| Закрытие шибера / подпрессовка вверх | 0,25 / 0,29 |
| **Цикл последовательно, 9 переключений по 0,1 с** | **5,59** |
| Цикл с перекрытием (подпрессовка вверх и закрытие шибера во время возврата) | 4,86 |

Независимая проверка через `ops/gates/calc_gates.py`: каждая фаза разбита на ступени давления, давление ступени равно её максимуму.
- G-CYCLE даёт **6,77 с (FAIL)**. Из них 1,8 с приходится на 18 «переключений» между ступенями давления, которых в машине нет.
- С 9 реальными переключениями выходит **≈ 5,87 с**, запас к 6 с всего 2 %.
- Обе модели консервативны в разных местах. Вывод: **6 с при 30 кВт достижимо, но без перекрытия фаз впритык.**

Средняя мощность: 8–14 кВт. Пиковая: 30 кВт (ограничена регулятором). Установленная мощность: 30 + шнек 2,2 + вентилятор охладителя 0,55 + мешалка 0,75 + управление 0,5 ≈ **34,0 кВт** (≤ 34,2 по C-PWR-01, запас мал).

## 6. Физическая приёмка против BP500

- Сила 1,52 МН и давление на торце 169 МПа соответствуют BP500 (1700 кгс/см²).
- Давление 270 / 300 бар — в пределах BP500 (≤ 300).
- Цикл 5,6–5,9 с (≤ 6 с) соответствует 600 брикетам в час.
- Мощность 30 кВт равна мощности BP500.
- Масса брикета 0,83 кг, длина 86 мм — в пределах 40–110 мм.

Порядки величин совпадают. Масса и габарит машины здесь не считаются, их проверяет шаг 2 (G-MASS, G-ENV).

## 7. Риски и вопросы (кому)

1. **Кривая уплотнения** — заглушка. От неё зависят ρ_die, работа и длина высокого давления. → **T-1.1** (литература с DOI). Если кривая жёстче, цикл выходит за 6 с.
2. **Запас по циклу** 2–5 % без перекрытия. Нужно решить, перекрывать ли фазы или ставить аккумулятор ~5 л: он заряжается на выдержке, разгрузке и шибере и подаёт масло на возврат. Также — проверка насоса 360 л/мин на 30 кВт. → **T-1.4**.
3. **Окно подачи шнека.** Камера подпрессовки заполняется только при поднятой подпрессовке, на это есть ≈ 1,6–2 с. Нужно ~9,2 л рыхлого материала (90 кг/м³) за ≤ 1,6 с, то есть ≥ 5,8 л/с. Обычным шнеком это недостижимо, нужен дозатор-накопитель или шнек большого сечения. → **T-1.2**.
4. **Дозирование по массе** при объёмной камере. → **T-1.2**.
5. **Упругое восстановление 10 % и зазор ≤ 0,3 мм** на сторону при 169 МПа: требование к упругой деформации вкладыша (C-CLR-01). → **T-1.2**, шаг 2 FEA.
6. **Стяжки** (если выбрана схема с ними). Статика при 1,85 МН: As ≥ 1 082 мм² на стяжку (42CrMo4, n = 1,5). На 10⁷ циклов при коэффициенте нагрузки Φ = 0,2 и σ_ASV ≈ 40 МПа (VDI 2230) нужно **As ≈ 1 700 мм², то есть M56** (вилка M56…M72 при Φ = 0,15…0,35). → шаг 2.
7. **Гейты (T-0.2a) — закрыто 25.11:** после исправления G-PFACE / G-DOSE (потребно 210 мм) / G-CYCLE (5,87 с) — PASS. Было:
   - Формула потребного хода в G-DOSE считает длину брикета дважды: даёт 288 мм против физических 210. С ходом 230 гейт выдаёт FAIL, хотя ход выбран верно.
   - G-CYCLE считает каждую ступень давления отдельным переключением.
   - Ход под гейт не подгонялся.
