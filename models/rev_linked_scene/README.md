# Ограниченные связанные synthetic-сцены A/B

Из корня репозитория, Python 3.12 и стандартная библиотека:

```sh
python3 models/rev_linked_scene/run.py
python3 -m unittest discover -s models/rev_linked_scene -p 'test_*.py'
python3 -m unittest discover -s models/kinematic_press -p 'test_*.py'
python3 scripts/check_registry.py --check-git
```

`results/report.json` сохраняет входы каждой фазы восьми сцен, независимый реестр тел, все неупорядоченные пары, точные интервалы, отдельные результаты касания и обязательной связи, continuity и события. Там же — 19 именованных отрицательных примеров с полным доказательством; `results/registry_snapshot.yaml` — снимок реестра. Хэши локальных файлов, источника и снимка находятся в JSON. `fixtures.json` — только условные входы, не параметры REV.

Осевые AABB движутся линейно и синхронно в фазе. `engine.pair` делит время на корни шести неравенств пересечения, границы окна и корни пересечения границ области контакта; каждая точка и каждый открытый интервал рассматриваются отдельно. Изменения знаков между корнями невозможны для заявленного класса. Разрешённый контакт задан конкретной парой, передней x-гранью первого тела, задней x-гранью второго, допустимой yz-областью, временем и правилом направления. Другие поверхности в рамках этого правила запрещены; иные способы движения не поддерживаются. Одновременно обязательная связь проверяет покрытие указанного окна отдельно от статуса контакта. `combine_link` консервативно объединяет результаты по фазам; неизвестный интервал не становится подтверждённой связью.

Реестр тел фиксируется отдельно от формирования всех пар. `C`, `W_in`, `G_out` используются как области, а не твёрдые препятствия. CREATE/SPLIT в общем случае не реализованы и дают INDETERMINATE; поддерживается проверка конкретного synthetic REMOVE по границе и указанной приёмной области. Времена и положения на границах проверяются, исчезновение остатка без события блокирует переход. Запретная коллизия остаётся видимой при неизвестности другой пары. Представленные сцены — ограниченные условные геометрии, а не описание конструкции REV или исчерпывающая проверка всей установки.

Для B открытие упора и замка показано отдельными движениями, а закрытый READY проверяет их условное геометрическое положение. Для A удержание и для B разгрузка — только обозначенные synthetic предпосылки; фактические силы, удержание, разгрузка, выдача и безопасность остаются UNKNOWN. `READY` и `GEOMETRY_SUFFICIENT` относятся исключительно к условным сценам. Никакие реальные испытания не проводились; G1 открыт.
