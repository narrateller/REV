# Исследовательская проверка геометрии, SYNTHETIC ONLY

Из корня репозитория, Python 3.12, только стандартная библиотека:

```sh
python3 models/kinematic_press/model.py
python3 -m unittest discover -s models/kinematic_press -p 'test_*.py'
```

Фактические результаты: `results/report.json`, `results/synthetic_phases.svg`, `results/registry_snapshot.yaml`. В fixtures — полностью условные значения в метрах и секундах; они не являются параметрами REV. `input_template.json` сохраняет неизвестные параметры обеих альтернатив. Запуск проверяет заданные пары, а не всю установку; в JSON отражено отсутствие полного набора пар и геометрии для каждой фазы. Для задания собственных synthetic пар использовать `--fixtures PATH --out PATH`; путь входа должен находиться в репозитории для записи хэша.

Тела — заданные осевые прямоугольные призмы и синхронные линейные трансляции за интервал. Все координаты — целые или строки рациональных чисел; расчёт точный на `Fraction`. Касание считается коллизией. Алгоритм пересекает по времени решения шести линейных неравенств; пустое пересечение доказывает отсутствие контакта на всём интервале для заданной пары. В отчёте проекции — одновременное XY-перекрытие, пересечение XY-траекторий центров — без времени; неопределённые параллельные случаи диагностируются как null. SVG изображает только начало и конец, не доказательство всего хода.

Проверка выдачи — отдельное сравнение координаты заднего края с границей выхода при заданном максимальном ходе в +x. Она не устанавливает, что траектория свободна от всех препятствий, и не доказывает реальную выдачу. Для неизвестных данных возвращается INDETERMINATE; противоречие — INVALID_INPUT. Физически согласованная реальная фазовая геометрия, реальные допуски и неопределённости, взаимодействие сырья, физические разрешения и силовой путь не оценены. Модель не утверждает архитектуру, реальную безопасность, VAL или G1. Независимый review метода и результатов необходим.

## Фазы, пары и силовые контуры

`phase_plan.json` определяет фазы A/B, исследовательский перечень обязательных проверок пар и условные силовые цепи на основе эскизов и таблиц циклов. Это не исчерпывающий перечень опасностей реальной машины: неподвижные элементы задаются явно нулевым перемещением, пустое пространство нельзя представлять твёрдым телом. Предусмотренные сопряжения и допускаемый контакт требуют отдельной модели; при политике касания они дают COLLISION. Для A-OUT сохранена связь с A-PRESS, перед B-OPEN требуется физическое подтверждение разгрузки.

`phase_inputs_synthetic.json` содержит условные, намеренно разнесённые тела во всех 13 фазах; это набор демонстрационных кинематических проверок, не геометрия работающего пресса. Обработчик `evaluate_phases` отдельно запускает каждую пару с явно заданными общим интервалом, координатами и траекториями; отсутствующие фазы и тела не подставляются. В `report.json` разделы `synthetic_phase_coverage` и `rev_phase_coverage` содержат `checked_pairs` и `unchecked_pairs`; численные примеры не приписываются REV. Для самостоятельного исследования используйте `--phase-inputs models/kinematic_press/phase_inputs_synthetic.json` и формат этого файла. Пригодность самих перечней, разрешений и условных силовых контуров требует независимой проверки; полный набор реальных геометрий, допусков и движений отсутствует.

`results/force_paths.svg` изображает предполагаемые цепи реакций без подтверждения соединений, удержания, величин сил, жесткости и прочности. Для B разгрузка материала не доказывается низким давлением; для A удержание и запуск пустого канала остаются неизвестными. `ejection` должен быть объектом; `[]` и другие неверные типы дают `INVALID_INPUT` для выдачи, независимо от проверки столкновения.


## Изменения по REV-R5-IMPL-02-001

Исследовательская матрица теперь строится из всех неупорядоченных пар независимо заданного состава сцены, а не только ранее выбранных пар. `*_wall` — отдельные твердые стенки, а не заполненная полость рамы, канала или направляющей; отсутствующие части остаются UNKNOWN. Контакты силовых соединений не объявлены допустимыми автоматически. Свободный объём проверяется отдельным запросом занятости; он не становится частью конструкции. Перечни и исключения подлежат повторной проверке R5.

`synthetic_phase_coverage` и `rev_phase_coverage` перечисляют результат каждой пары; результаты относятся к условной разнесённой геометрии, а данные REV остаются неизвестными. Дополнительные именованные примеры в `fixtures.json` показывают столкновения при различных фазах, включая промежуточные; `transition_fixtures.json` содержит отрицательные и положительные проверки фаз. Все времена и входные законы явные, поддержано только `motion_type: linear`; иное или неизвестное движение даёт INDETERMINATE. `synthetic_transitions` проверяет порядок, время, совместимость геометрии на границах, заданные synthetic-разрешения и результаты пар, `synthetic_a_out_relation` требует общего движения с A-PRESS. Возврат прежних разнесённых примеров теперь сопоставляется с исходным READY и не подтверждается при несовместимых границах; он не подтверждает очистку продукта или разгрузку. Список запретов движений ограничен явно указанными в `MUST_STAY` и `NEVER_SIMULTANEOUS`, а не полным анализом безопасности.

Флаги разрешений в synthetic примерах — входные допущения, не измерения. Низкое давление не является `unloading_confirmed`. Допуски, ожидаемые контакты силовых интерфейсов, фактическая связь продвижения изделия и пуансона, реальные защитные функции и корректность полной физической последовательности не доказаны. Скалярная проверка хода не доказывает полную выдачу. Исторический акт R5 сохранён: его `STALE` означает только что новые файлы отличаются от проверенного SHA; оба blocker остаются OPEN до независимого recheck.


## Связная выдача по ARB-R1-RECHECK-03

Запуск из корня после основного прогона:

```sh
python3 models/kinematic_press/model.py
python3 models/kinematic_press/run_linked.py
python3 -m unittest discover -s models/kinematic_press -p 'test_*.py'
python3 verification/r5_model_02/independent_check.py
python3 scripts/check_registry.py --check-git
```

`results/linked_report.json` содержит восемь результатов одного параметризованного сцены A/B: достаточный и короткий ход, столкновение и неизвестная связь. Для каждой фазы указаны тела, интервалы и все неупорядоченные пары заранее определённого состава; удаление изделия допускается только после успешной связной беспрепятственной выдачи. Пара punch/product обрабатывается как особый интерфейс: точное совпадение передней и задней x-граней, совместная трансляция и заданная положительная общая yz-площадь. Для B контакт stop/lock также требует совпадающих x-граней без проникновения; разрешение контакта не распространяется на другие пары. При отсутствии входа пара остаётся UNKNOWN.

Случай столкновения содержит интервал product/препятствие [1/4, 7/8]; переход заблокирован независимо от скалярной достаточности хода. CE-01 проверяет согласованность scalar-полей с геометрией и запрет ложного A-OUT, CE-02 — обнаружение punch/channel_wall самой фазовой матрицей с блокированием перехода. Предыдущая проверка только по scalar не способна доказать достаточную связную выдачу и теперь возвращает INDETERMINATE.

Для успешного synthetic выхода изделие удаляется явным событием после доказанного выхода; пуансон возвращается заданным ходом, для B упор и замок закрываются отдельно. READY сверяется с независимой координатной спецификацией, свободными запросами объёмов и закрытием/зацеплением stop/lock. Состояние пустого столба A, разгрузка B и работоспособность замка — только synthetic предпосылки, без подтверждения физики, сил или безопасности REV. Точные параметры реальной установки по-прежнему UNKNOWN. R5-IMPL-01/02 не закрываются до независимого RECHECK.


## Непрерывность после REV-R5-RECHECK-04-001

Решение R1 — `verification/r5_recheck_04/disposition.md` на `791d0ce8ccb31373b221d0b69063e2f835b442c0`; исходный акт сохранён рядом. Препятствие collision задано с начала сцены. На всех исходах runner проверяет время, геометрию и жизненный цикл каждой границы; отсутствие неизвестных дополнительно обязательно для трёх исходов с заданной геометрией. Подтверждённый разрыв блокирует переход и READY, неизвестная непрерывность без доказанного блокера оставляет INDETERMINATE. Коллизия выводится отдельно и не скрывается неопределённостью.

Тесты создают мутации положения, времени, lifecycle и неизвестной непрерывности, а также проверяют одновременно доказанную коллизию. R5-IMPL-02 закрыт только для ранее проверенной синтетической области commit `576a17fc`; изменённый код требует регрессионной проверки R5. R5-IMPL-01 остаётся OPEN до независимого положительного RECHECK.
