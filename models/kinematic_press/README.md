# Исследовательская проверка геометрии, SYNTHETIC ONLY

Из корня репозитория, Python 3.12, только стандартная библиотека:

```sh
python3 models/kinematic_press/model.py
python3 -m unittest discover -s models/kinematic_press -p 'test_*.py'
```

Фактические результаты: `results/report.json`, `results/synthetic_phases.svg`, `results/registry_snapshot.yaml`. В fixtures — полностью условные значения в метрах и секундах; они не являются параметрами REV. `input_template.json` сохраняет неизвестные параметры обеих альтернатив. Запуск проверяет заданные пары, а не всю установку; в JSON отражено отсутствие полного набора пар и геометрии для каждой фазы. Для задания собственных synthetic пар использовать `--fixtures PATH --out PATH`; путь входа должен находиться в репозитории для записи хэша.

Тела — заданные осевые прямоугольные призмы и синхронные линейные трансляции за интервал. Все координаты — целые или строки рациональных чисел; расчёт точный на `Fraction`. Касание считается коллизией. Алгоритм пересекает по времени решения шести линейных неравенств; пустое пересечение доказывает отсутствие контакта на всём интервале для заданной пары. В отчёте проекции — одновременное XY-перекрытие, пересечение XY-траекторий центров — без времени; неопределённые параллельные случаи диагностируются как null. SVG изображает только начало и конец, не доказательство всего хода.

Проверка выдачи — отдельное сравнение координаты заднего края с границей выхода при заданном максимальном ходе в +x. Она не устанавливает, что траектория свободна от всех препятствий, и не доказывает реальную выдачу. Для неизвестных данных возвращается INDETERMINATE; противоречие — INVALID_INPUT. Полная фазовая геометрия, реальные допуски и неопределённости, взаимодействие сырья, физические разрешения и силовой путь не оценены. Модель не утверждает архитектуру, реальную безопасность, VAL или G1. Независимый review метода и результатов необходим.

## Фазы, пары и силовые контуры

`phase_plan.json` определяет фазы A/B, исследовательский перечень обязательных проверок пар и условные силовые цепи на основе эскизов и таблиц циклов. Это не исчерпывающий перечень опасностей реальной машины: неподвижные элементы задаются явно нулевым перемещением, пустое пространство нельзя представлять твёрдым телом. Предусмотренные сопряжения и допускаемый контакт требуют отдельной модели; при политике касания они дают COLLISION. Для A-OUT сохранена связь с A-PRESS, перед B-OPEN требуется физическое подтверждение разгрузки.

`phase_inputs_synthetic.json` содержит два отдельных учебных примера пар. Обработчик `evaluate_phases` отдельно запускает каждую пару с явно заданными общим интервалом, координатами и траекториями; отсутствующие фазы и тела не подставляются. В `report.json` разделы `synthetic_phase_coverage` и `rev_phase_coverage` содержат `checked_pairs` и `unchecked_pairs`; численные примеры не приписываются REV. Для самостоятельного исследования используйте `--phase-inputs models/kinematic_press/phase_inputs_synthetic.json` и формат этого файла. Пригодность самих перечней, разрешений и условных силовых контуров требует независимой проверки; полный набор реальных геометрий, допусков и движений отсутствует.

`results/force_paths.svg` изображает предполагаемые цепи реакций без подтверждения соединений, удержания, величин сил, жесткости и прочности. Для B разгрузка материала не доказывается низким давлением; для A удержание и запуск пустого канала остаются неизвестными. `ejection` должен быть объектом; `[]` и другие неверные типы дают `INVALID_INPUT` для выдачи, независимо от проверки столкновения.
