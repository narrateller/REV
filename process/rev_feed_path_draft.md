# REV — путь сырья и интерфейсы, документальная схема

R1 / codex-01; T-INIT; база main `0b54471e9e5a7f148558804c93d3302f19907ce4`.
Статус DRAFT: логический маршрут по сведениям оператора, не обследованная
производственная схема и не утверждённая граница поставки. Источники:
`process/feedstock.md`, `process/supply_boundary_options.md`, OP-REV-01…11
в `ISSUES_AND_TASKS.md`, `requirements/system_requirements.md` и постановка
`verification/r2_compaction_data/specification.md`.

```text
Древесные отходы из строительного мусора
           │
           ▼
Сортировка → удаление металла → дробление → просев
     существующие операции, логический порядок; фактическая трасса UNKNOWN
                                              │
                               SP-REV-05 / T: кандидат передачи
                               после дробления и просева
                                              │
               транспорт / буфер / ответвления / допподготовка
                        наличие, последовательность и границы UNKNOWN
                                              │
                               SP-REV-06: кандидат входа пресса
                                              │
                  ПРЕСС: приём → дозирование → уплотнение → выдача
                                              │
                               U: предварительный выход пресса
                                              │
                   дальнейшее обращение с брикетом UNKNOWN
```

SP-REV-05 и SP-REV-06 — разные обозначения, не установлено, совпадают ли их
физические места. Стрелки задают только логические функции, не реальную
компоновку, непрерывность, доступную точку отбора или порядок повторных
проходов. Схема A с каналом/зажимом и B с закрытой камерой/выталкиванием —
варианты реализации функций пресса, не выбранная архитектура.

## Что нужно установить для интерфейса

- По существующим сведениям и последующему согласованию с оператором — точное
  физическое положение T, поток после просева, возможные ответвления и границы
  соседних участков. Информация о транспортировке и буфере остаётся UNKNOWN по
  прямому указанию пользователя; не принимать её за проектное решение.
- Для будущих границ входа пресса — состояние и изменчивость сырья, режим
  поступления, свободная мощность подготовки, накопленные остатки, условия
  управления и обязанности при отклонениях. Значения UNKNOWN.
- Для функций пресса — способ проверки движения, массы отдельной дозы и
  выдачи; масса дозы является входом для оценки формования VAL-REV-03, а
  повторяемость готового брикета и выдача оцениваются отдельно.
- Для возможной дополнительной подготовки и контроля включений — место,
  применимость и распределение ответственности после исследования; отсутствие
  информации не доказывает отсутствия или наличия операции.
