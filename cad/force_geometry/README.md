# T-R4-FORCE-GEOMETRY-01 — геометрические входы R3

[Манифест поставки](../source/force_geometry/manifest.json) содержит 44 исходные привязки, 52 интерфейса и 42 записи `case ID → interface ID → CAD-объект и определяющие UNKNOWN`. Ключ интерфейса совпадает с исходной таблицей. В документе FCStd эти ключи видны в группе ForcePath; объекты `IF_*` содержат блокеры, фазовые требования к контактам и имена связанных CAD-объектов.

## Входной аудит и область геометрии

Аудит выполнен относительно [манифеста входов claim](../../coordination/tasks/T-R4-FORCE-GEOMETRY-01/input_manifest.json). Привязки BASE_A/BASE_B сохранены с исходными единицами, статусами, идентификаторами и ревизиями. В FCStd модули ходов и геометрические размеры задаёт редактируемая Spreadsheet в метрах. FreeCAD пересчитывает примитивы в миллиметрах. Для локальной оболочки камеры X идёт вдоль хода, поперечные Y/Z центрированы. Ноль относительных ходов служит локальной базой графика. Для возврата направление меняется, модуль остаётся исходным. Фактическая база машины и начальная позиция пуансона неизвестны.

Четыре FCStd содержат объём внутренней оболочки камеры, отдельные калибры длины продукта и занятого сырьём участка, круг номинального сечения штока и четыре калибра относительного хода. Самостоятельные калибры и ходы можно показать через группы References и TravelGauges. V1 хранит топологию заднего привода с направляемым носителем, V2 — бокового привода с портальной траверсой. Варианты A и B сохраняют разные требования к реакционной цепи: удержание материала/столба для A и упор, блокировка и последующая разгрузка для B. Координаты силовых звеньев исключены из размерной части, пока их нельзя привязать к фактическим узлам.

Для расчётов R3 определяющие блокеры включают координаты и направления опор, рабочие контактные стороны, податливость и зазоры, эксцентриситеты и свободные длины во всех позах, характеристики сечений и материалов, геометрию двусторонних захватов и фазовые нагрузки. Для V2 отдельно нужны боковой вынос и податливость портала в обеих плоскостях; для V1 — задние зазоры и свободная длина носителя. Подробные причины и фазовые зависимости указаны по каждому интерфейсу и случаю в манифесте. Область поставки — условные геометрические ссылки; все 42 расчёта физической геометрии отмечены `BLOCKED_INPUTS / NOT_RUN`.

## Воспроизведение

Из корня репозитория с FreeCAD/Part 1.0.0 и системным Python:

```sh
git lfs pull
output_root=$(mktemp -d)
/usr/bin/python3 -B cad/force_geometry/rebuild.py --out "$output_root/rebuild"
/usr/bin/python3 -B cad/force_geometry/verify_output.py --check-git
```

Указанный каталог rebuild создаётся скриптом. Проверка открывает поставленные модели, проверяет SHA-256, фактические размеры, знаки, полноту интерфейсов и case ID, затем повторяет построение во временном каталоге. Для проверки редактируемости она меняет длину камеры в памяти и проверяет пересчитанную форму. Контроль воспроизводимости сравнивает свойства и форму открытых объектов. SHA-256 в манифесте относится к опубликованным байтам FCStd, чьи метаданные архива могут меняться при сохранении.
