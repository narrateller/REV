# W02 B · контакт ключей, итерация 02

При 315 бар в поршневых полостях обоих цилиндров и 0 бар в обратных
полостях осевой расчётный упор составляет 3,092505 МН. Для условия
`CALCULATED_ASSUMED` запас контакта двух ключей и их опор составляет
**1,881** при требовании **≥1,5**. Это минимум по проверенной сетке
эксцентриситетов, жёсткостей и погрешностей установки.

| Ветвь B при 315 бар | Пик R3, МПа | Номинальный пик r2, МПа | Пик с разбросом r2, МПа | Запас с разбросом |
| --- | ---: | ---: | ---: | ---: |
| Ключи | 224,940 | 111,753 | 132,918 | **1,881** |
| Седло | 122,673 | 84,757 | 106,165 | 2,355 |

## Геометрия и материалы

- Два ключа 72 × 380 × 70 мм вместо 60 × 250 × 70 мм. Координата
  центра каждого ключа увеличена по модулю с 190 до 200 мм. Номинальная
  плоская площадка с фаской 1 мм на каждом торце составляет 70 × 378 мм.
  В расчёте чувствительности эффективная площадка составляет 68 × 376 мм.
- Затвор 640 × 400 × 210 мм. Опускание ключей увеличено до 430 мм.
  Зазор до затвора при опущенных ключах 40 мм. До нижней направляющей
  остаётся 30 мм. Зазор от поднятого затвора до пуансона 60 мм.
- Опорная траверса утолщена локально двумя интегральными приливами по
  60 мм с радиусом у корня 12 мм. Толщина в силовом сечении под тягами
  280 мм. Матрица B отведена на 5 мм по X, чтобы сохранить 3 мм до затвора
  при номинальном выборе зазора до седла. Ширина входного прохода,
  крепления тяг и выпускное отверстие сохранены.
- Условные пределы затвора и ключей из 42CrMo4+QT или квалифицированного
  аналога составляют 500 МПа. Для опор, седла и траверсы сохранён
  условный предел 250 МПа по материалу эффективного сечения. Он
  определяет обе контактные ветви. Повышение предела как единственная
  мера потребовало бы минимум 337,41 МПа у обеих деталей исходной
  определяющей пары. Увеличение двух существующих площадок даёт
  требуемый запас при 250 МПа. Для варианта с дополнительным рядом
  понадобилось бы определить последовательность выбора зазоров и
  распределение реакций по четырём опорам. Правки каталога COTS
  не потребовались.

## Контакт, допуски и границы

Обе ветви R3 проверены раздельно. Для номинала использованы его
односторонний аффинный закон и точное интегрирование областей сжатия.
В анализе чувствительности каждая площадка имеет свою осевую
жёсткость на единицу площади и свою плоскую погрешность. Базовая
жёсткость равна `E / 660 мм` по длине осевого пути от переднего торца
затвора до тыльной плоскости прилива. Независимые множители
0,75 / 1,00 / 1,25, смещения плоскостей ±0,025 мм и перекосы
±0,015 мм на кромках, взятые по каждой координате, дают 5 184
сочетания для каждой ветви. Проверены девять пар эксцентриситетов
Y = −75/0/+75 и Z = −30/0/+30 мм. Интегралы дают силу и первые
моменты F·e_y, F·e_z. В худшем сочетании ключи несут приблизительно
2,120 и 0,972 МН.

Номинальные осевые зазоры затвор–ключ и ключ–опора 0,25 мм каждый.
Допуск ±0,10 мм на каждый зазор сохраняет минимум 0,15 мм для
ненагруженного движения. Зазор до седла после выбора обоих зазоров
1,50 мм номинально и 1,20 мм по сумме допусков. В расчётной сетке
податливость даёт остаток ≥0,610 мм до первого касания седла.
Монтажное отклонение ключа от центра площадки ±0,5 мм по Y и Z
учтено внутри исключённого краевого пояса. В CAD отдельно проверены
перекрытия торцов пары затвор–ключ–опора, торец опоры на траверсе и
ветвь седла. Запасы по условному сечению затвора ≥2,402, по полосе
траверсы без учёта приливов 1,943. Для пути через опору пик перенесён
по проекции пятна без расчётного выигрыша от распределения по подошве.

Постановка даёт номинальное пиковое давление на сжатой площадке.
Локальные концентрации у кромок, связь податливостей реальных деталей,
усталость, монтажный контакт и привод ключей требуют подтверждённых
входов. Физическая оценка имеет статус `BLOCKED_INPUTS`. Открытые
вопросы R3 по направляющим при рассогласовании и по реверсу одной
ветвью переданы вместе с новыми входами.

## Воспроизведение и передача

Из корня репозитория с материализованными объектами Git LFS.

```powershell
python cad/force_geometry/redesign_1p5mn_02/screen_contact.py
$cadPython = 'C:\Users\user\AppData\Local\Programs\FreeCAD 1.1\bin\python.exe'
$replay = Join-Path ([IO.Path]::GetTempPath()) ('w02-b-replay-' + [guid]::NewGuid())
& $cadPython cad/force_geometry/redesign_1p5mn_02/build_native.py --out $replay
python cad/force_geometry/redesign_1p5mn_02/verify_output.py --check-git --replay $replay
```

FreeCAD проверяет по 19 сочетаний хода и положения затвора на сборку, полный непрерывный
ход ключей и затвора без нагрузки, площади контакта, повторное открытие
FCStd и изменение положений через свойства `Design`. Сборки содержат
раздельные детали, редактируемые привязки движения и нативные листы
TechDraw c BOM r2. Контуры строятся из scoped registry при повторной
сборке. Команда `--replay` сопоставляет измеренные свойства и
контактные площади без привязки к служебным полям архива FCStd.
