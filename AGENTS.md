# Вход для автоматизированного агента

До изменения проектных файлов прочитать AGENT_PROTOCOL.md, затем STATE.md.
Далее выполнять Boot Sequence и назначение роли из AGENT_PROTOCOL.md.
Исходное состояние — TEMPLATE. DEMO-параметры не являются данными изделия.
Самостоятельно не выставлять VERIFIED, LOCKED или PASSED без предусмотренных доказательств.

Для запроса «Войди в курс дел и текущий статус проекта» прочитать NEXT_MODEL.md после STATE.md, проверить текущие SHA и действительность эстафеты. Дать статус и предложить следующий шаг.
