## Порядок валидации и данные

Проект требований/плана → независимый review → решение пользователя по G1 →
согласованная программа/условия/средства → независимое рассмотрение программы →
отдельное разрешение выполнения → исходные записи/результаты → независимая оценка.
Решение G1 не подтверждает VAL-REV-20 или будущую серию; испытания сейчас не разрешены.

TEST-F-01 — приём/подача; TEST-F-02 — дозирование и входная масса; TEST-F-03 —
формование/состояние изделия; TEST-F-04 — полная выдача; TEST-F-05 — интеграция
с учётом всех отказов, остатка, потерь и смен партии. Масса дозы не проверяет
массу/геометрию брикета. Полную серию и невыданные/негодные изделия не исключать.

changeover и ревизии. Неизвестная доля/масса — null с причиной, не ноль/равное деление.
