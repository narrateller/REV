# Исправление v1.2.1 для Windows

Основание: журнал Git.txt пользователя, два сбоя из 68 тестов.

- Исправлен разбор указателя Git LFS с переводами строк LF и CRLF.
- Демонстрационное доказательство записывается в байтовом формате с LF, без
  неявного преобразования Windows. Тестовая фикстура синхронизирована.
- `.gitattributes` запрещает преобразование строк Git, сохраняя исходные байты
  всех файлов и их SHA256. Текстовые различия доступны через Git diff.
- При проверке Git LFS доказательств в commit учитывается SHA256 реального
  файла из указателя; рабочая копия по-прежнему должна содержать реальный файл.
- Добавлены тесты CRLF-указателя, Git с core.autocrlf=true и проверки
  материализованного LFS-артефакта по Git-указателю.

71 тест пройден локально в Linux, включая смоделированные CRLF. Фактический
запуск на Windows, в GitHub и в средах моделей не выполнялся. Исходная
версия 1.2 не менялась. Если ранее создан проект с реальными данными, его
не перезаписывать архивом: миграцию, проверку прежних commit и доказательств
нужно выполнять отдельно. Историю Git автоматически не переписывать.
