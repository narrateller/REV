# Инженерный отказ T-R3-FORCE-CALC-03

FAILED / CALCULATED_ASSUMED. Выпуск КД блокируют два результата.

1. **Выбор зазора при рассогласовании цилиндров.** Для A-V2 и B-V2
   на противоположных давлениях 315 бар расчётный остаток зазора
   при шарнирных опорах направляющих равен −2,141874 мм. При условной
   полной заделке остаток +0,210215 мм. Определяющие строки
   529/541 для A-V2 и 1417/1441 для B-V2. При реверсе одной ветвью
   с 315 бар в кольцевой полости и разгруженной противоположной
   ветвью те же варианты дают −0,536182 мм при шарнирных опорах.
   Нужны жёсткости опор и связанных узлов, ширина допустимого
   рассогласования по реальному контуру и контактная модель после
   сближения пуансона с камерой. Реакции после сближения — null.
   [Сочетания с предписанными давлениями](results/pressure_bounds.jsonl)
2. **Полный аварийный реверс одним цилиндром.** В S42-010/020 (A)
   для −1,532417 МН требуется до 508,524 бар подачи, то есть
   503,524 бар в кольцевой полости. В S42-031/042 (B) для −1,502417 МН
   требуется до 498,814 бар подачи, то есть 493,814 бар в полости.
   Предельное давление полости 315 бар. Доступный путь удержания,
   изоляция ветвей и достижимая нагрузка при аварийном переключении
   требуют подтверждённого гидравлического контура и постановки.
   [Индексы и нагрузки](results/index.json)
