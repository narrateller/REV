# Инженерный отказ T-R3-FORCE-CALC-02

`FAILED / CALCULATED_ASSUMED`. Физические входы — `BLOCKED_INPUTS`.
В штатной огибающей у 42 исходных ID проверены предусмотренные
удерживаемые ветви. Зарегистрированы 116 исключений при освобождении
продольной связи. Следующие результаты блокируют передачу в выпуск КД.

1. **Ветка ключей B, предельное давление в полостях.** Два цилиндра при
   315 бар в поршневых полостях и нулевом обратном давлении дают 3,093 МН
   при статическом заклинивании. Для смещений `|e_y| = 75 мм` и
   `|e_z| = 30 мм` тяжёлая площадка несёт около 2,152 МН. Пиковое
   давление составляет 224,94 МПа, запас 1,111 при требовании 1,5.
   Для той же схемы при 250 бар в полостях линейное масштабирование
   даёт 178,52 МПа и запас 1,400. Среднее по площадке, использованное
   в R4, пропускает этот отказ. Для повторной проверки требуется
   обоснованная граница давления на закрытой ветви или изменение
   контакта ключей и их опор. [Результаты и определяющие строки](results/index.json)
2. **Зазор при рассогласовании.** У A‑V2 при противоположных давлениях
   315 бар расчётный остаток зазора при шарнирных концах направляющих
   падает до −2,142 мм. В пределе заделки остаётся +0,210 мм. Для оценки
   допустимого рассогласования нужна жёсткость креплений и связанная
   модель направляющих, пуансона и камеры. Нагрузки после выбора зазора
   имеют значение `null`. [Сочетания](results/pressure_bounds.jsonl)
3. **Аварийный реверс одной ветвью.** Для полного заданного реверса A
   требуется до 508,524 бар подачи, для B — до 498,814 бар. После вычета
   падения подачи по 5 бар превышается предельное давление полости
   315 бар. Гидравлическое удержание и подключение независимой осевой
   ветви к реальной машине имеют статус `UNKNOWN`. [Состояния аварийного реверса](results/index.json)

Запас по телу штока, траверсе, устойчивости или механическому ходу не
закрывает отказ в контакте ключей. Формулировка отказа относится к
проверенным допущениям и границам давления W02. Для точного результата
по узлам требуются указанные в [аудите](input_audit.md) входы.
