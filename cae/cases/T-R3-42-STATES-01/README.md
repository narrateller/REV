# Аудит 42 нагрузочных состояний REV

Первая поставка для R4 по эстафете T-R3-42-STATES-01. Claim R3 принят в main
коммитом `bc42800c88d9f01b58da4d5f9d29f31e3e994783`. Сессия R3
`6afd08f5-9174-8191-ba01-ebb86011c0d3`. Хэши и исходные Git-объекты
зафиксированы в [манифесте входов](../../../coordination/tasks/T-R3-42-STATES-01/input_manifest.json).

- [Аудит по case ID](case_audit.json) содержит источник, фазу, систему координат,
  знаки, единицы, условия закрепления и определяющий пробел для каждого случая.
  42 случая имеют статус `BLOCKED_INPUTS`. Фактические нагрузки, моменты,
  опорные реакции и запасы оставлены `null`.
- [Запрос R4](r4_interface_requests.json) связывает 52 интерфейса с точными case ID.
  Для каждого интерфейса нужны источник и область применимости численных фактов,
  система осей, поза или диапазон хода, единицы, допуск при наличии либо причина
  `UNKNOWN`. Для A-V1 и A-V2 требуется подтвердить независимый путь реакции
  при пустом пуске. Для B-V1 и B-V2 нужно отразить контакты упора и замка
  при нагрузке, разгрузке, открытии и повторном замыкании. Для V2 нужны подписанные
  плечи бокового цилиндра. Для V1 требуется проверить несоосность по всему ходу.
- [Условные осевые расчёты](../../../drives/T-R3-42-STATES-01-axial.json) охватывают
  восемь именованных reference cases. Для них рассчитаны заданный осевой спрос,
  усилие и номинальное напряжение штока, проверен баланс идеальных осевых реакций.
  Входы взяты из исходных 44 привязок fixed-budget и проверены по ревизиям.
  Геометрия и двусторонние связи в этом расчёте идеализированы. Результат относится
  только к указанной модели передачи заданного усилия.

R4 передаёт точный SHA принятого в main пакета и путь манифеста. R3 сверяет строки
`case ID → interface ID` с этим пакетом, повторяет затронутые расчёты и проверки
и регистрирует остаточные пробелы до итогового merge. Помимо геометрии для
фактического расчёта требуются фазовые нагрузки, их приложения и остаточные
реакции согласно аудиту каждого случая.

Из корня репозитория, Python 3.12.14 / PyYAML 6.0.3:

```bash
python cae/cases/T-R3-42-STATES-01/verify_output.py
python verify_output.py --check-git
python scripts/check_registry.py --check-git
python -m unittest discover -s tests -v
```

Первая команда повторяет расчёты и побайтно сверяет
[артефакты](output_manifest.json) с сохранёнными. Для этой поставки она использует
точные исходные привязки, каталог форка и символическую геометрию R4 из плана эстафеты.
