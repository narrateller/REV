# Расчётная инженерная огибающая граничных условий

**Design Boundary & Phase Load Envelope, v1.** Входы `READY_ASSUMED`, расчёт `NOT_RUN`. Огибающая задаёт конечный набор статических проверок чувствительности. Её диапазоны — принятые масштабы сравнения, физические пределы и экспериментальные данные отсутствуют. [Исходные физические блокеры](blockers.md) сохраняются для всех 42 случаев.

[`envelope.json`](envelope.json) содержит 42 ID, 16 фазовых постановок, точки относительного хода, дискретные усилия и допустимые в модели ветви передачи. [`assumptions.json`](assumptions.json) содержит явные допущения. Исходная `main` — `b1f0243f86fef672902bd462b8567a3ec7066f59`, геометрия R4 — `a56a62e36a1f2a1e7d1d6081d7c9ec7d5e49ab4a`. Хэши источников и четырёх FCStd записаны в огибающей. Осевые ссылки для каждого варианта берутся из восьми воспроизведённых случаев. Номинальные габариты, диаметр штока и относительные ходы берутся из привязок четырёх FCStd. Исходные ревизии и их зрелость сохраняются в манифесте R4.

## Нагрузки и позиции

- Оси суррогата `+X` к выходу, `+Y` к боковому приводу V2, `+Z` вверх. `F_x > 0` означает сжатие штока, `N = −F_x` положительно на растяжение. Метры, ньютоны, ньютон-метры и паскали.
- `WORK` равен +1 532 417,45 Н для A и +1 502 417,45 Н для B. `RETURN` равен −12 000 Н для обеих семей. `REVERSE_WORK` меняет знак `WORK` для статической чувствительности аварийного случая. `ZERO` задаёт отдельный контрольный расчёт без нагрузки. Перенос `WORK` на подход, остаток или переход — допущение для сравнения нагрузочных путей. Масса, инерция, вес, трение, гидравлический переходный процесс и время исключены из этой модели и остаются неизвестными для машины.
- `q` — относительное удлинение от нуля шкалы R4. Каждая фаза использует концы своего условного отрезка и середину, отдельные фазы используют фиксированную позу. Нагрузочные отсчёты независимы от `q`. Для возврата проход по шкале обратный. Для фаз открывания и закрывания B `q` относится к пуансону. Ход упора по этим координатам не определяется.
- Выполни декартово произведение заданных `q`, ненулевых нагрузок, допустимых ветвей удержания, шагов опор и поперечных смещений. `ZERO` достаточно выполнить один раз на case ID. Для каждой ненулевой нагрузки отдельно сравни освобождённую осевую ветвь. Сохраняй задающие сочетания для экстремумов. Все точки относятся к дискретной постановке.

## §4. Опоры, контакты и реакции

Два соосных по X сечения направляющих `G−` и `G+` находятся на `x = q − s/2` и `x = q + s/2`. Варианты `s = L_chamber/2` и `s = L_chamber` — сценарии чувствительности. В удерживаемой ветви в этих сечениях действует жёсткое в поперечных направлениях идеальное ограничение Y/Z с нулевой осевой реакцией и без локального опорного момента. Каждая знаковая составляющая представляет свою сторону пары противоположных односторонних контактов. Поворот вокруг X и местные напряжения в контактах эта схема оставляет вне расчёта.

Сила привода `+F_x` приложена к жёсткой подвижной группе на `y = y_a`, `z = 0`. Осевое противодействие выбранной ветви `−F_x` приложено на `y = e_y`, `z = e_z`. Обе точки находятся на `x = q` в этой модели. `y_a = 0` для V1 и `y_a = W, 2W` для V2. `e_y ∈ {−W/2, 0, +W/2}`, `e_z ∈ {−H/2, 0, +H/2}`. `W` и `H` — номинальные внутренние ширина и высота камеры. Масштабы иллюстрируют чувствительность и не задают измеренные допуски или плечи.

Суммарные моменты пары на подвижной группе `M_y = −F_x e_z` и `M_z = F_x(e_y − y_a)`. Для базовой сверки `R_{+y} = −M_z/s`, `R_{+z} = M_y/s`, `R_− = −R_+`. Реакции направляющих действуют на подвижную группу. На раму действуют противоположные силы от направляющих, `−F_x` на креплении привода и `+F_x` на выбранной осевой ветви. Проверь баланс сил и моментов для обеих групп. Реакции реального фундамента и распределение по монтажным болтам выходят за границы модели.

В удерживаемой ветви осевой упор имеет нулевую податливость в активном направлении. Опоры A в пустом пуске задаёт отдельная условная оснастка. Для B рабочие предельные варианты последовательно приписывают полное усилие либо опорному месту закрытого упора, либо условной цепи через замок. Распределение нагрузки между ними не определено. При открытом упоре оснастка держит пуансон отдельно, реакция раскрытого контакта равна нулю по определению этой ветви. В расчёте с освобождённой осевой ветвью внешняя оснастка и осевой упор отсутствуют. При `F_x ≠ 0` продольное равновесие невозможно, результат — `NO_STATIC_EQUILIBRIUM`. При `F_x = 0` это свободная продольная степень свободы с нулевым заданным усилием. Не фиксируй её искусственно для получения реакции.

## §5. Прочность идеализированных элементов

Шток — сплошной круг с номинальным `d` по R4, шарнирная осевая передача без изгиба в этой модели. `A = πd²/4`, `I = πd⁴/64`, `σ = N/A`. Носитель/траверса — отдельное контрольное сплошное сечение `W × H`, которое принимает полное `N` и оба момента огибающей. `A = WH`, `I_y = WH³/12`, `I_z = HW³/12`. Посчитай напряжения `σ_x = N/A + M_y z/I_y − M_z y/I_z` по четырём углам сечения. Это упрощённое сравнение комбинаций сечения. Для штока и сечения укажи `max |σ|` и отношение к условным 235 МПа, без вывода о допуске. Материал сравнения имеет `E = 210 ГПа` и условный предел 235 МПа. Реальные материалы, пластика, сварные швы, захваты, замки, болты, контактные напряжения и усталость требуют отдельных входов.

## §6. Устойчивость

Заданы условные свободные длины `L_rod(q) = d + q` и `L_carrier(q) = L_chamber + q`. Рассчитай `P_cr = π² E I/(K L)²` для круглого штока и обеих плоскостей прямоугольного сечения только для сопоставления с `N < 0`. Сравни `K = 1` (шарнир–шарнир) и `K = 2` (заделка–свободный конец) как отдельные идеальные постановки. По каждому сочетанию выведи гибкость `K L/√(I/A)`, `|N|/P_cr` и сравни `P_cr/A` с принятым пределом 235 МПа. Если упругая модель выходит за область применимости, явно пометь результат как сравнение и укажи причину. Эксцентриситеты учитываются в проверке напряжений §5, а не в линейной собственной задаче Эйлера. Связанная устойчивость рамы и эффект второго порядка требуют отдельной модели.

## Воспроизведение и статус

Из корня репозитория с материализованными FCStd из Git LFS:

```bash
python cae/cases/design_boundary_phase_load_envelope/verify_output.py --check-git
python cae/cases/T-R3-42-STATES-01/verify_output.py
python cae/cases/T-R3-42-STATES-01/verify_r4_handoff.py
/usr/bin/python3 -B cad/force_geometry/verify_output.py --check-git
```

Только первая команда проверяет эту огибающую. Остальные воспроизводят её источники. Рабочие результаты сохранять отдельно под `T-R3-42-STATES-ENVELOPE-01`, со статусами `CALCULATED_ASSUMED`, `NO_STATIC_EQUILIBRIUM` или `NOT_RUN` и указанием расчётной области. G1 остаётся открыт, W02 и физическая готовность остаются `NO-GO`.
