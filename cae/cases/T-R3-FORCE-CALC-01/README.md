# T-R3-FORCE-CALC-01

Воспроизводимый скрининг 42 ID огибающей по номиналам R4 в области
`CALCULATED_ASSUMED`. [Аудит](input_audit.md) содержит расхождения
CAD, области применимости референсов и физические блокеры.
[Сводка](summary.json) связывает экстремумы и индексы, начиная с 0, с
[42 журналами](results/). [Энергобаланс по фазам](../../../drives/r3_force_calc_01.json)
и [реестр допущений](../../../params/r3_force_calc_01.json) относятся к этой ревизии.

## Постановка и формулы

- Исходные q, знаки и ветви заданы `DB-ENVELOPE-V1`. Ненулевая сила
  без удерживающей ветви оставляет продольную невязку `F_x`, статус
  `NO_STATIC_EQUILIBRIUM`. В ZERO продольная степень свободы свободна.
  Для возврата отсчёты идут от полного выдвижения к нулю. При переключении
  замка q описывает положение пуансона. Каждая точка помечена по номинальному
  ходу COTS. За пределом хода результат представляет алгебраическую чувствительность.
- На подвижную группу действуют `F_x` от привода и `−F_x` от удерживающей
  ветви. Моменты пары `M_y=F_x(z_a−e_z)`, `M_z=F_x(e_y−y_a)`.
  Две станции направляющих дают `R_+=(0,−M_z/s,M_y/s)`, `R_−=−R_+`.
  Станции идеальны в Y/Z, свободны по X, локальный опорный момент
  отсутствует. Суммы F и `r × F` проверяются по каждой оси для подвижной
  группы и рамы. Вектор реакций рамы в журнале описывает приложенные к ней
  силы на интерфейсах. Индивидуальные опоры фундамента требуют схемы крепления.
- §4. При `N=−F_x` номинальное осевое напряжение штока `N/A`.
  Для носителя приведены четыре угла условного сплошного сечения
  `N/A + M_y z/I_y − M_z y/I_z` при передаче полного результирующего
  усилия и момента. Для пуансона приведено среднее давление `F_x/(WH)`
  при полном прижатии. Местные изгиб, напряжения рамы, камеры, контактов
  и допустимые напряжения требуют геометрии и свойств исполнения.
- §5. Идеальная осевая устойчивость при сжатии по Эйлеру
  `P_cr=π²EI/(KL)²`. Линейная модель сравнивает 0,400 м штока и 0,310 м
  носителя с K = 1 и 2. Эйлер применяется для сравнительного скрининга.
  При `P_cr/A ≥ 235 МПа` его упругая применимость не подтверждена.
- §6. Определены усилия на креплении цилиндра, переносе через шток и
  носитель, двух условных станциях и осевой ветви. В закрытой ветви B
  упор воспринимает контактную силу с передачей полной нагрузки либо через
  седло, либо через замок. В открытой ветви B реакции упора и замка нулевые
  по условию. Для несущей способности нужны данные из аудита входов.
- Привод. В прямой идеальной передаче `p=|F_x|/A_active`,
  `Q=A_active v`, `P_h=pQ`, `W=∫|F_x|dq`. Давление вычислено для
  одной активной полости при нулевом противодавлении и потерях.
  Пиковое усилие на всём интервале q задаёт сценарий постоянной нагрузки,
  а времена по расходу и энергии — отдельные идеальные нижние границы.
  Фазовые оценки нельзя складывать в физический цикл из-за перекрывающихся
  сценариев и неизвестных профилей. Удержание, разгрузка и переключение B
  при фиксированном q требуют отдельных расходов, давлений и времени.

Физические результаты имеют `value: null` с причиной. Обновления до
`VERIFIED` требуют независимого акта. Нормативная классификация готового
продукта, физические испытания и выпуск КД для изготовления остаются
за пределами расчётного скрининга.

## Результаты

Из 2 462 сочетаний 2 304 с удерживающей ветвью, 42 контрольных ZERO
и 116 без статического равновесия. 884 строки попадают за предел
номинального хода. Определяющие сочетания доступны в сводке.

| Условная величина | Результат |
| --- | ---: |
| Максимальная поперечная реакция станции, S42-011 | 2,835 МН |
| Максимальный модуль номинального осевого напряжения Ø45, S42-001 | 963,5 МПа |
| Максимальный модуль напряжения угла условного сечения, S42-011 | 35,76 ГПа |
| Максимум сжимающей нагрузки к идеальной критической, шток, K = 2 | 2,351 |
| Идеальный предел Ø80/45 при 250 бар, выдвижение / втягивание | 125,66 / 85,90 кН |
| Требуемые идеальные давления WORK A / B | 304,86 / 298,90 МПа |
| Требуемые идеальные давления REVERSE_WORK A / B | 445,97 / 437,24 МПа |
| Минимальное время двойного прохода 636,39 мм при 40 л/мин | 8,08 с |
| Работа при постоянном WORK A / B на интервале 351,11 мм | 538,05 / 527,52 кДж |

Энергобюджет сравнения 30 кВт × 6 с составляет 180 кДж. Для постоянного
пика на рабочем интервале нужно в идеале 17,94 с для A или 17,58 с для B
при 30 кВт. При 250 бар гидравлическая мощность на 20–40 л/мин равна
8,33–16,67 кВт. Верхняя точка превышает 15 кВт даже при КПД = 1.
WORK и аварийный реверс выходят за идеальную силовую возможность текущего
кандидата, а 400 мм не покрывают шкалу q. Возврат −12 кН попадает в
идеальный диапазон сил (3,49 МПа). Его полный ход и фактическое время открыты.

Напряжения выше области упругого сравнения показывают, где условная
линейная постановка исчерпала применимость. Числа не пригодны для
определения реального запаса.

## Воспроизведение

Python 3.12+ и PyYAML из `requirements.txt`. Из корня репозитория с
материализованными исходниками из Git LFS:

```text
python cae/cases/T-R3-FORCE-CALC-01/verify_output.py --check-git
python scripts/check_registry.py --check-git
python -m unittest discover -s tests -v
python verify_output.py --check-git
```

Для записи пересчитанных файлов запустить первый скрипт с `--write`.
Проверка в CI использует сохранённые файлы, сверяет входные Git blobs/LFS,
балансы, знаки, ветви, пределы привода и воспроизведение байт в Git.
[Входной манифест](input_manifest.json) · [Хэши выходов](output_manifest.json)
