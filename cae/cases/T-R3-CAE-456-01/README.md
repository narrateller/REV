# T-R3-CAE-456-01 — реакции, прочность и устойчивость (§§4/5/6)

Результат `CALCULATED_ASSUMED` в области `ASSUMED_STATIC_SCREENING`.
[Манифест](manifest.json) фиксирует происхождение и SHA256 входов, решателя
и результатов. Расчёт всех сочетаний повторно выполнен штатным решателем
`T-R3-42-STATES-ENVELOPE-01` по утверждённой
[Design Boundary & Phase Load Envelope v1](../design_boundary_phase_load_envelope/README.md).

## Входной аудит и расчётная постановка

- Покрытие включает 42 case ID, 16 фазовых профилей, восемь условных осевых
  ссылок и четыре материализованных FCStd. Номинальные размеры и параметры
  хода взяты из огибающей, интерфейсы сверены с аудитом исходных состояний.
  Использованные масштабы и свойства сравнения имеют зрелость `ASSUMED`.
  [Огибающая](../design_boundary_phase_load_envelope/envelope.json) ·
  [Допущения](../design_boundary_phase_load_envelope/assumptions.json)
- Координаты заданы в метрах в системе R4. Ось +X направлена к выходу,
  +Y к боковому приводу V2, +Z вверх. Сжатие соответствует `F_x > 0` и
  `N = −F_x < 0`. Дискретные значения силы и позы независимы.
  В фазах открытия и закрытия B поза относится к пуансону.
- §4. Противоположные поперечные реакции направляющих уравновешивают
  моменты пары `M_y = −F_x e_z` и `M_z = F_x(e_y − y_a)`.
  На G+ реакция `(0, −M_z/s, M_y/s)`. На раме действуют противоположные
  векторы в тех же точках. Размерность момента — Н·м, реакции — Н.
  Упор и замок B заданы отдельными предельными ветвями. В открытой ветви B
  нагрузку несёт внешняя условная оснастка, раскрытый контакт свободен.
- §5. Условный сплошной шток работает осево по `σ = N/A`. Четыре угла
  сплошной прямоугольной траверсы проверены по
  `σ = N/A + M_y z/I_y − M_z y/I_z`. При `A` в м² и `I` в м⁴
  все слагаемые имеют размерность Па. Модули напряжений сопоставлены с
  условным пределом 235 МПа. Выход линейной модели за этот предел отмечен
  в числах сравнения.
- §6. При сжатии вычислены `P_cr = π²EI/(KL)²` в Н, безразмерные
  `KL/√(I/A)` и `|N|/P_cr` для штока и двух осей траверсы.
  `E = 210 ГПа`, `K = 1` и `K = 2`, `L_rod = d + q`,
  `L_carrier = L_chamber + q`. При `P_cr/A ≥ 235 МПа` результат Эйлера
  маркирован как сравнительный из-за выхода за условный предел.
- Алгебраическая статика исключает массу, инерцию, вес, трение, время и
  ресурс. Сетка, шаг времени и соответствующая сходимость неприменимы.
  Дискретные экстремумы относятся к перечисленным сочетаниям.

## Результат

[Сочетания](samples.jsonl) содержат силы и точки приложения, реакции и
невязки двух свободных тел, напряжения штока и углов сечения и показатели
устойчивости. [Сводка](summary.json) даёт диапазоны строк, экстремумы,
интерфейсы R4 и физические блокеры по каждому case ID. Нумерация строк с 1.

| Величина | Экстремум | Сочетание |
| --- | ---: | --- |
| Поперечная реакция одной направляющей | 2,00036 МН | S42-011, строка 591 |
| Модуль осевого напряжения штока | 81,29 МПа | S42-001, строка 2 |
| Модуль напряжения контрольного сечения | 3235,10 МПа (13,77 × 235 МПа) | S42-011, строка 591 |
| Отношение `\|N\|/P_cr` | 1,611 | S42-006, `carrier_y`, `FIXED_FREE`, строка 290 |

Из 3672 сочетаний 3456 удерживаемые, 42 с заданной нулевой нагрузкой при
свободной осевой степени свободы, 174 с освобождённым осевым путём под
ненулевой нагрузкой. Для последних сохранены `NO_STATIC_EQUILIBRIUM`,
осевая невязка и `null` для §§4/5/6 с причиной.

Авторская проверка охватывает балансы сил и моментов с абсолютными
порогами 1e−8 Н и 1e−8 Н·м, центральное нагружение, контроль ZERO,
освобождение осевой связи и растяжение. При одинаковых нагрузках и плечах
реакция удваивается при уменьшении шага направляющих вдвое. Проверены
четырёхкратное уменьшение `P_cr` при переходе от `K=1` к `K=2` и
зависимость `P_cr ∝ L⁻²` для разных поз. [Акт R5](../../../coordination/verifications/T-R5-ENGINEERING-VERIFY-01.json)
относится к предыдущему пакету на указанном в акте SHA.

Физические §§4/5/6 во всех 42 случаях имеют `BLOCKED_INPUTS / NOT_RUN`.
Физические нагрузки и связи, реакции, прочность и устойчивость указаны
как `UNKNOWN` с `null` и причинами. Нужны подтверждённые нагрузки и точки
приложения, реальные сечения и материалы, опоры и контакты, свободные длины
и характеристики соединений. [Источники блокеров](../design_boundary_phase_load_envelope/blockers.md)

## Воспроизведение

Из корня репозитория с Python 3.12+ и материализованными FCStd из Git LFS.

```text
python cae/cases/T-R3-CAE-456-01/verify_output.py --check-git
python scripts/check_registry.py --check-git
python -m unittest discover -s tests -v
python verify_output.py --check-git
```

Для сохранения вычисленных выходов при повторной генерации добавьте
`--write` к первой команде.
