[огибающей R1](../design_boundary_phase_load_envelope/README.md).
Проверены [точные входы и хэши](../../../coordination/tasks/T-R3-42-STATES-ENVELOPE-01/input_manifest.json)
для `main` `4dd5031601cdaf731c84ca1460b4df8e8b33c07e` и геометрии R4
`a56a62e36a1f2a1e7d1d6081d7c9ec7d5e49ab4a`.
Работу выполнила сессия R3 `6afd08f5-9174-8191-ba01-ebb86011c0d3`
после принятия claim `5c97f3918fd116df362863373517ee0b75ae4980`.

## Покрытие и определяющие сочетания

Выполнены 3 456 сочетаний с удержанием и 42 нулевых контроля по 42 case ID.
Для каждого из 52 ненулевых отсчётов отдельно проверена освобождённая осевая
ветвь. В каждой такой ветви непогашенный остаток вдоль X равен заданному
`F_x`. Результат `NO_STATIC_EQUILIBRIUM`, напряжения и устойчивость
`NOT_RUN`. Нулевые контроли сохраняют свободную продольную степень свободы.

| Величина в условной постановке | Максимум | Первый определяющий ID |
| --- | ---: | --- |
| Модуль поперечной реакции одного сечения направляющей | 2,00036 МН | `S42-011/H0010` |
| Модуль момента вокруг Z | 574,657 кН·м | `S42-011/H0010` |
| Модуль осевого напряжения круглого штока | 81,290 МПа | `S42-001/H0001` |
| Модуль углового напряжения контрольного сечения носителя | 3,235 ГПа | `S42-011/H0010` |
| Отношение `abs(N)/P_cr` для носителя, изгиб вокруг Y, `K = 2` | 1,611 | `S42-006/H0037` |

Угловое напряжение превышает условный предел 235 МПа в 13,77 раза и
характеризует выход линейного сравнения за принятый предел. Для определяющего
сравнения устойчивости носителя `P_cr = 0,95117 МН` при гибкости 140,04.
У штока определяющее отношение к Эйлеру равно 0,06653. Соответствующее
`P_cr/A = 1,222 ГПа` превышает принятый предел, поэтому упругая формула
здесь служит только сравнением. По всем осевым сжимающим сочетаниям отмечены
14 580 таких сравнений и 1 296 сравнений с `P_cr/A` ниже предела.

Попарные проверки рабочих пиков четырёх вариантов подтвердили двукратный
рост поперечной реакции при уменьшении шага опор вдвое, четырёхкратный рост
`abs(N)/P_cr` при переходе от `K = 1` к `K = 2` и рост в 2,273 раза
от начала к концу рабочего участка через изменение свободной длины носителя.

## Расчёт и чтение результатов

- [results.jsonl](results.jsonl) содержит одну JSON-запись на сочетание.
  `id` связывает выборку и результаты §§4–6. Поля `H` обозначают удерживаемые
  сочетания, `ZERO` — нулевой контроль, `RELEASED` — сравнение без осевой
  связи. Вся сетка геометрических отсчётов для освобождённой ветви покрыта одним расчётом
  продольного остатка, независимого от плеч, шага и позы.
- [summary.json](summary.json) содержит максимумы по случаю, варианту и всей
  огибающей, первый задающий ID и число точных совпадений. Там же сохранены
  исходные физические блокеры для каждого случая и попарная проверка
  чувствительности.
- [output_manifest.json](output_manifest.json) фиксирует хэши входного
  манифеста, кода и артефактов, команды и расчётную среду.

§4. Векторы имеют порядок X/Y/Z. Сечения направляющих расположены в
`q ± s/2`, осевой привод на `(q,y_a,0)`, противодействие в
`(q,e_y,e_z)`. При `M_y = −F_x e_z` и `M_z = F_x(e_y − y_a)`
поперечные компоненты `G+` равны `−M_z/s` по Y и `M_y/s` по Z.
Знак показывает сторону приложения реакции к подвижной группе. На раму
действуют противоположные векторы. Для каждой группы проверены суммы сил и
векторных моментов в общей точке O. Численный порог 64 ULP от масштаба
суммируемых компонентов относится к вычислительной проверке. Наибольшие
остатки составили 0 Н и 1,46·10⁻¹⁰ Н·м. Альтернативные ветви упора B
получают полный заданный осевой компонент по отдельности. Физическое
распределение между ними остаётся неизвестным.

§5. Положительное `N = −F_x` соответствует растяжению.
Шток даёт только `N/A` для круглого номинального сечения.
Для контрольного прямоугольника `W × H` вычислены четыре значения
`N/A + M_y z/I_y − M_z y/I_z`. Записаны знак каждого напряжения, модуль
максимума и отношение к условным 235 МПа.

§6. При сжатии рассчитаны `P_cr = π²EI/(K L)²` и гибкость
`K L/√(I/A)`. Длины штока и носителя равны `d + q` и `L_chamber + q`
соответственно. Для круглого штока обе оси эквивалентны, у носителя
плоскости Y и Z учтены отдельно. Отдельный флаг фиксирует выход
`P_cr/A` на принятый предел текучести или выше. Второй порядок,
материальная нелинейность и связь с рамой в постановку не входят.

Все 42 условных случая получили `CALCULATED_ASSUMED` после прогона.
У всех 42 физических случаев сохранены `BLOCKED_INPUTS / NOT_RUN`.
Расчёт охватывает заданную дискретную сетку и идеализированные пути передачи.
Фактические силы, соединения, опоры, материал и допустимость требуют своих входов.

## Воспроизведение

Python 3.12.14, материализованные модели Git LFS. Команды из корня репозитория:

```sh
python cae/cases/design_boundary_phase_load_envelope/verify_output.py --check-git
python cae/cases/T-R3-42-STATES-ENVELOPE-01/verify_output.py --check-git
python -m unittest discover -s cae/cases/T-R3-42-STATES-ENVELOPE-01 -v
python verify_output.py --check-git
python scripts/check_registry.py --check-git
python -m unittest discover -s tests -v
```

Верификатор пересчитывает сочетания и побайтно сверяет артефакты.
Для осознанной регенерации используется `--check-git --write`.
