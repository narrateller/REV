# Основа КД W02 1,5 МН

В [четырёх сборках](../../../cad/source/force_geometry/redesign_1p5mn/manifest.json) сохранены нативные страницы `AssemblyDrawing` A3 с основной надписью, видом сбоку, планом, видом со стороны выдачи и видом силовой ветви. Три габаритных размера ассоциативно привязаны к вершинам проекций. На листе указаны ход, расстояние между станциями направляющих и сечения. Второй лист `BOMDrawing` связан с таблицей `PartsList` и выводит идентификаторы деталей, количество и ссылки на позиции COTS. Позиции, ожидающие рабочего проектирования, помечены в ведомости.

При последующем выпуске открыть `AssemblyDrawing` и `BOMDrawing` в FreeCAD TechDraw. Для PDF использовать печать листов в PDF и проверить первые пять байт `%PDF-`. SVG и DXF получать командой экспорта страницы TechDraw. В DXF для геометрии детали 1:1 использовать модельный профиль, масштаб страницы 1:30 относится к обзорному листу. Для всех форматов проверить проекции, размеры, основную надпись и привязку BOM. Здесь поставлены редактируемые исходники для этого этапа.
