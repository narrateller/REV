# W02, итерация 04

Экспорт для проверки R5 содержит четыре нативные сборки FreeCAD и 154 листа
(4 общих вида и 150 листов компонентов) в PDF, DXF и SVG. На каждом листе
три ортогональные проекции и габаритные размеры в мм. Повторяющиеся экземпляры
одного типа в одинаковой ориентации перечислены на общем листе. Связь листов,
экземпляров и файлов с SHA-256 задана в [манифесте](output/manifest.json).

В графе спецификации с пометкой COTS указан ключ из
[каталога](../../drives/cots_catalog.yaml). Позиция W02-201 учитывает два
цилиндра на сборку. Чертежи составных тел этой позиции отражают CAD-огибающую
интерфейса. Для закупки нужны размеры и рейтинги конкретного поставщика.
Сборочные листы имеют нестандартный формат для сохранения 1:1. При печати нужно
отключить подгонку к странице. Для больших PDF применяется PDF UserUnit.

## Входной аудит

- База геометрии `83407d0844c34735a11af2fbdd2698e5cd909354`, каталог
  `redesign_1p5mn_04`. Четыре FCStd сверены с SHA-256 манифеста и LFS в
  закреплённом коммите. Проекции построены через TechDraw из этих FCStd.
- Расчёт T-R3-FORCE-CALC-05 использует те же геометрию и базис. Для
  `CALCULATED_ASSUMED` подача составляет 143,794 бар при рабочем ходе и
  293,534 бар при одноветвевом реверсе. Запасы штока, траверсы и ключей B
  равны 4,365, 2,636 и 2,234. Отношение сжатия к нагрузке Эйлера 0,1204.
  Остаточный зазор 1,566 мм рассчитан после вычета общего бюджета подгонки
  0,75 мм. Привязки интерфейсов заданы по +X к фильере, +Y поперёк и +Z вверх.
- Оператор принял условную огибающую для подготовки КД. Исходный вердикт R3
  `FAILED` и статус 42 физических состояний `BLOCKED_INPUTS` сохранены.
  При осевом освобождении расчёт даёт 116 сочетаний без статического
  равновесия. Рейтинги цилиндров, схемы переключения, жёсткость установленных
  опор и фазовые реакции требуют подтверждения.
- Бюджет подгонки задаёт общий расчётный предел. Поэлементное распределение
  монтажных допусков, посадки, параметры резьб, требования к сварке и
  шероховатости требуют отдельной деталировки и утверждения. Листы содержат
  номинальные габариты и спецификации из CAD, а также геометрию отверстий по
  проекциям. Для рабочего комплекта остаются размерные цепи отверстий,
  разрезы и технологические требования. Выпуск в производство требует
  отдельного решения оператора.

## Воспроизведение и проверки

Для экспорта используется Python из FreeCAD 1.1.4 / OCCT 7.8.1 с `pypdf`.
Для независимого разбора DXF используется `ezdxf`. Верификатор в CI
проверяет сохранённые артефакты и Git-хэши стандартной библиотекой Python.

```powershell
$fc = 'C:/Users/user/AppData/Local/Programs/FreeCAD 1.1/bin/python.exe'
& $fc -m pip install pypdf
& $fc drawings/W02/export_iteration_04.py --out "$env:TEMP/w02-iteration-04"
python -m pip install pypdf ezdxf
python drawings/W02/verify_iteration_04.py --check-git --parse
python scripts/check_registry.py --check-git
python -m unittest discover -s tests -v
python verify_output.py --check-git
```
