## Исправление R5-IMPL-01: SYN-LINKED-EJECTION

R4 реализует **один сценарий с параметром variant=A/B** и общими инвариантами,
а не независимые примеры, подобранные для отдельных скалярных ответов.

1. Участники сцены определены заранее: punch, product, feeder/gate, твёрдые
   стенки channel/guide/frame; для B — stop/lock. Общая временная база,
   линейные синхронные движения и все границы соседних фаз заданы явно.
2. Связь punch/product проверяется по геометрии на всём интервале выдачи:
   передающая грань пуансона совпадает с задней гранью изделия, допустимая
   yz-область контакта задана, нет взаимного проникновения, движение согласовано.
   Равенства delta или словарей недостаточно. Предусмотренный контакт — отдельный
   проверяемый интерфейс, не безусловное исключение пары и не глобальное
   отключение `touch_is_collision` для остальных тел.
3. Для A выдача связана с A-PRESS, A-OUT — тот же участок/overlay; для B —
   B-UNLOAD → раздельные разрешённые открытие/отвод stop/lock → B-EJECT.
   Разгрузка/удержание здесь только явно помеченные synthetic предпосылки,
   не доказанные физические состояния REV.
4. Геометрический конец выдачи вычисляется из product и границы выхода
   в конце связанного движения; available_stroke не является независимым
   доказательством. Если прежние scalar-поля оставлены для совместимости,
   проверять их согласованность с геометрией; противоречие INVALID_INPUT,
   а не SUFFICIENT_STROKE. Известный корректный короткий ход не считается
   противоречием. Неизвестная связь → INDETERMINATE, известное нарушение
   инварианта → BLOCKED/явное нарушение контракта, не положительная выдача.
5. Непрерывность сохраняется для каждого сохраняемого тела и времени всех
   внутренних фаз/возврата. Удаление/замена product — явное событие жизненного
   цикла только после подтверждённой выдачи; материал не исчезает из камеры
   ради совпадения наборов тел.
6. READY — собственный проверяемый предикат: пуансон в разрешённом исходном
   положении, feeder/gate в рабочих состояниях, окно/выход свободны, для B
   stop/lock возвращены и замкнуты; для A состояние столба явно задано.
   Изделие может быть удалено с доказанным состоянием. Копирование конца фазы
   с True-флагами и обнулением delta не доказывает READY. Нельзя «телепортировать»
   feeder/gate/lock в исходные координаты без заданного движения.

## Четыре ожидаемых исхода одного сценария

Базовый выдающий участок: punch x=[-1,0], product x=[0,1], совпадающая область
yz, граница полной выдачи x=2; движение в +x. Начальные контакты/допуски
определены явно для synthetic модели; неизвестные данные не заполняются нулями.

| Исход / мутация для каждого A и B | Ожидаемый результат повторной проверки |
|---|---|
| Достаточный свободный ход: совместное продвижение на 2, препятствий нет | Задняя грань product достигает 2 по геометрии; связность доказана; SUFFICIENT_STROKE, все запрещённые пары NO_COLLISION при полной матрице. Возврат/жизненный цикл дают рабочий READY, переходы ALLOWED при полных synthetic разрешениях |
| Короткий ход: совместное продвижение на 1, препятствий нет | Задняя грань product достигает 1; INSUFFICIENT_STROKE независимо от отсутствия коллизий. Не разрешать зависимые переходы, требующие уже полной выдачи; не выдавать ложный READY поверх остатка изделия |
| Столкновение: твёрдое препятствие x=[3/2,7/4] в той же yz-области, базовый ход | Матрица сама выдаёт COLLISION; для product/препятствия ожидается интервал [1/4,7/8]. Запрещён зависимый переход, сцена не получает положительный итог. Отдельно обязательна мутация punch/channel_wall в B-EJECT из CE-02 |
| Неопределённая связь: нет необходимого определения контакта/траектории product | Связная выдача INDETERMINATE с причинами; положительный scalar/overlay не подменяет связь. Если при этом уже доказана запрещённая коллизия, она сохраняется и не скрывается общей неопределённостью |

Известно неподвижное product при движущемся punch не является успешным
сценарием: конкретно нарушенная связь должна быть зарегистрирована.
При неподвижных телах и ложном available_stroke=2 ожидается ошибка
согласованности scalar с геометрией, а не SUFFICIENT_STROKE (CE-01).
Четыре исхода относятся к связи выдачи и не заменяют раздельные поля
collision/ejection/transition/READY и их доказательства.

## Исправление R5-IMPL-02: матрица от полного состава сцены

- Для каждой фазы и переходного участка перечислить все потенциальные
  неупорядоченные пары тел из **независимо заданного состава сцены**, а не
  из концов уже выбранных required_pairs. Все твёрдые препятствия входят;
  отсутствие нужной геометрии — UNKNOWN, не автоматическое исключение.
- Каждая пара имеет CHECK либо проверяемое EXCLUDED/интерфейсное основание
  с типом, областью времени, условием/доказательством. Пары ожидаемого контакта
  проверяются по контракту поверхности/движения/непроникновения; отсутствие
  запретной коллизии и допустимость контакта — разные результаты.
- Статическое разнесение можно исключить только при доказанной неподвижности
  и разнесении конкретных тел. Все такие доказательства пересчитываются после
  изменения геометрии/движения/фазы. Неподвижное препятствие не «нерелевантно»
  только потому, что оно само не движется.
- UNKNOWN/необоснованное исключение блокирует зависимый вывод о полноте;
  отчёт сохраняет пары, основания, ошибки и фактические результаты, а не
  только счётчик. Для каждого допустимого контакта есть отрицательная мутация.
- Мутация CE-02: переместить только channel_wall на начальную призму punch
  в B-EJECT. **evaluate_phases/его преемник сам**, без ручного `check` reviewer,
  обязан включить/переоценить punch/channel_wall, обнаружить запрещённую
  коллизию на [0,1] и заблокировать зависимый переход. Результат 127/127
  выбранных пар при пропущенной паре не принимается как полнота.

Обязательный пакет нового точного code/results SHA для независимого R5:

   контакта, связной выдачи, непрерывности/жизненного цикла и рабочего READY.

   предыдущих применимых тестов; отчёты принадлежат текущему запуску/target.
5. Воспроизводимые команды, неизменённые входы/хэши, отдельные допущения
   synthetic контакта/разгрузки; никаких новых параметров REV или утверждений
   физики/безопасности. Исследовательский код не объявлять моделью сырья.

Только независимый RECHECK точного нового SHA может снять соответствующие
блокеры по фактическим доказательствам. Успешный арбитраж или зелёные старые
тесты этого не делают. Архитектура, ТЗ, реальная выдача и G1 не утверждены;
G1 остаётся открытым.
